# 2025–26 NBA 82 場賽季模擬

2026-10-12：新增完整30隊賽季流程。每隊82場，共1,230場例行賽；不含NBA Cup冠軍賽、附加賽或季後賽。

## 資料

`data/season-league.json` 包含582位球員、661個球員在隊版本、完整實際賽程及逐場出賽者。來源包括既有37份整季快照，以及新取得的球隊／球員逐場紀錄與5份中立場摘要，共44份NBA官方回應；保存網址、擷取時間及SHA-256。

每場採實際出賽紀錄作候選池，因此交易前後、缺席及季中加入不會被錯當成全季同場。來源不知道沒有出賽的DNP備援名單；零分鐘的官方出賽紀錄仍納入候選。沒有模擬傷病發生過程，也沒有輸入當場真實比分或分鐘。

5場中立場的兩隊在leaguegamelog都記為客場。海外賽使用官方GameSummary指定的兩側；兩場Cup準決賽的摘要仍未指定主客，因此以球隊ID固定A/B順序。這5場另外記中立戰績，不強制每隊41主場／41客場。

補查官方Location=Home/Road及v3 box score後，確認馬刺為40主場、41客場、1中立，雷霆為41主場、40客場、1中立。Cup西區準決賽的帳面homeTeam是雷霆、awayTeam是馬刺；若另做帳面主客展示，會是馬刺40主／42客，不能為湊41主場而把中立勝利歸給馬刺主場。既有賽季報告仍採中立獨立列示；其Cup A/B不是v3帳面主客。

## 建卡與輪替

能力由球員完整球季資料推導，交易球員的能力共用整季值，出手傾向與分鐘則採在隊數據。投射以100次出手的同季聯盟先驗收縮；其他可量測能力按同季輪替母體百分位。

防守資料實際欄位是 `PLUSMINUS`、`FG3A` 或 `FGA_LT_06`；使用出手樣本量收縮後反解防守曲線。缺資料採中性70，明確保存missingMeasurements。缺體重採中性肉體70，身高仍用實測值。無球、掩護、持球及破包夾尚無可靠獨立量測，全部為70。

輪替目標是各候選的在隊整季MPG，重新分配到240分鐘、單人上限48分鐘。前五個最高分鐘目標先發，依身高安排五位置；替補位置採身高級距。不是官方先發或位置，實際上場分鐘由既有輪替啟發式決定。

## 引擎與解讀

採現有 `timed-v1` 四節／延長賽模式，包含場內疲勞、替補、助攻、犯規與罰球籃板。每場重設體力；尚無主場優勢、跨場疲勞、旅行、暫停與完整空間模型。固定五人的stable-v1尚未驗證於timed，因此不套用。

這是使用同季能力、傾向與已知出賽者的回溯條件模擬，不是季前預測或留出驗證。一個seed只有一個實現球季，尚無多季分布。報告的真實W/L及場均數字僅作描述比較，不用來調整比賽機率或強制戰績接近真實結果。

各場檢查完成狀態、比分、各節得分、球員／球隊記帳、五人分鐘；未完成比賽直接報錯，不重抽到滿意結果。季末檢查30隊各82場、總勝和總敗均1,230、得失分與球員總計守恆。排名同勝場以淨分差與ID排序，不代表NBA正式種子排序。

## 舊OVR基準的資料問題

本輪發現 `scripts/build_benchmark_league.js` 讀取不存在的 `PCT_PLUSMINUS`／`D_FGA`，非有限值通過舊反解函式後落到99。現存固定五人資料150張卡的onBall/help全部99。其舊OVR／PR報告雖有seed穩定性，不能據此宣稱防守資料已正確建卡。

新的完整賽季流程獨立使用正確欄位並加來源回歸測試；沒有覆寫舊固定五人資料及OVR報告。舊基準需要另外修正建卡、重建資料並重跑評分，才能恢復其有效性。

## 執行

```sh
npm run season:fetch                       # 更新逐場與中立場快照，需要網路
npm run season:build                       # 從快照離線建卡及賽程
npm run simulate:season                    # 每隊82場，預設seed 20261012
npm run simulate:season -- --seed 20261013  # 另一季；保留既有seed報告
npm run test:season                        # 資料／賽程／記帳及已有報告重現
```

輸出 `reports/nba-season-2025-26-seed<seed>.md`／`.json`，以及每行一場完整球員box score的 `-games.jsonl`。程式、來源、建卡產物與box score雜湊保存在JSON；交易球員的總計依player ID合併，各在隊統計仍保留。

## 防守、分鐘與正負值診斷

`npm run diagnose:season` 依原seed重播1,230場，核對比分後從場上五人補算正負值，輸出 `reports/season-diagnostics.md`／`.json`。包含全部661個在隊版本的真實／模擬分鐘、得分、正負值與每48分鐘殘差，另列雷霆SGA在／不在場及模擬替補人數分組。

真實正負值來自在隊整季官方統計；模擬替補是每場輸入前五人以外的球員，尚無同口徑真實陣容時段。正負值殘差包含隊友、對手及全局模型偏差，不能直接逆推個人OVR，也不能換算誰造成幾場勝差。四組seed的雷霆分鐘實驗只更換目標，仍是軟輪替，尚非逐場完全鎖分鐘或真實換人時間重建。

新增官方對手統計、Home/Road篩選及兩場Cup v3 box score保存在 `data/diagnostic-source/`，診斷報告記錄來源網址與SHA-256。`npm run test:replay-accounting` 驗證得分／罰球與換人歸屬、時間／正負值守恆、延長賽及資料重現。

## 防守v1分支

`npm run simulate:season:defense` 改用獨立防守版本，來源追加1230份官方box score與30隊進階統計，見 `data/defense-source/game-exposure.json`。它使用官方先發、逐場分鐘軟目標、正常犯滿／死球輪替，加入失誤／抄截拆解、獨立壓迫訊號、投籃犯規條件機率修正、量測出手量與分區情境係數。原本的賽季與診斷產物不覆寫。

另有正規時間分鐘精確符合目標的固定曝光診斷排程；這個排程允許非死球換人並停用犯滿，而且不是真實陣容時段。其疲勞分布不能直接代替正常輪替來選正式參數。

防守效率比較使用雙方 `FGA−OREB+TOV+0.44FTA` 平均作分母，真實與模擬同口徑；標為代理值，不宣稱是NBA官方DefRtg。時鐘、分區情境係數由另一seed的123場全局指標探查，四個完整seed檢查隨機穩定性。所有建卡仍使用同季資料，尚非資料外預測。
