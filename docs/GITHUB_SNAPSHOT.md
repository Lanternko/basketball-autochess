## 收錄與排除

`scripts/github_snapshot.py` 產生以下清單：

- `reports/github-snapshot/included.csv`：收錄路徑、大小、原因。
- `reports/github-snapshot/excluded.csv`：留在本機的路徑、大小、原因。
- `reports/github-snapshot/summary.json`：數量與大小。清單本身不計入統計。

收錄所有研究程式及文件；結果採每檔上限與名稱規則篩選，並非所有中間資料。資料根目錄的應用資料，以及精簡 league／bio／manifest 元資料保留。原始 API 回應、逐場事件、runs、raw、checkpoint、大型診斷矩陣與快取留在本機。具體規則以腳本與清單為準。

`.gitignore` 預設忽略新增的 data／reports；已追蹤的精簡檔案仍正常更新。日後新增精簡產物時，先檢查清單，再明確 `git add -f` 選定檔案，避免意外上傳大量原始資料。

## 驗證與重現限制

`npm test` 通過 57 項檢查，以及 60 場完整比賽的帳務、輪替、時鐘、罰球、助攻、延長賽、重播與舊版一致性檢查。

GitHub 快照**不包含完整研究輸入**。部分歷史模型載入、artifact 測試、報表重建與完整 OVR 驗證需要先還原清單中相應的本機資料，否則會因缺檔失敗。既有 protocol／verification／hash 記錄描述原本完整本機執行，不代表這份精簡快照單獨即可重跑所有實驗。可先參照 `package.json` 與各版報告中的來源抓取、建卡及執行步驟；本次未承諾外部資料服務日後仍提供相同內容。
