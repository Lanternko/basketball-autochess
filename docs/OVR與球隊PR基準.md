## 2026-09-19 狀態與適用範圍

已建立可離線重跑的 2025–26 同季 30 隊異質陣容、固定對手池、seed、曝光與勝率映射。結果與驗收欄位見 [正式報告](../reports/strength-validation.md)、[完整 JSON](../reports/strength-validation.json)、[獨立 seed／費用診斷](../reports/strength-robustness.md)。

**這是「同季固定五人陣容」的球隊 PR，不是完整輪換 NBA 球隊排名。** 輪換口徑明定為各隊該季「在該隊累計上場分鐘最多的五人」，五人全程同場，沒有替補、傷病輪替或疲勞。不能省略這個限定，也不能拿前三名當成真實季後賽前三強。完整輪換與 tracking 外部效度仍未驗證。

## 資料及建卡

- `data/benchmark-source/` 保存 37 份 NBA 官方回應：30隊球員在隊 totals，加上全聯盟球隊、球員 base／advanced、身高體重、投籃區域與兩類防守 tracking。
- `data/benchmark-league.json` 包含 30 個唯一球隊 ID、150 張同季球員卡、來源網址／擷取時間／SHA-256 與完整轉換口徑；未以現有五支跨季測試隊冒充聯盟。
- 選人只看在隊累計分鐘，不看模擬勝率或誰能讓誤差最小。能力採該球員完整球季資料（包含交易前後）；投籃傾向採在隊資料，兩者明確區分。依整季累計分鐘選人不保證五人曾實際同場；交易球員也可能出現在兩隊的季節性陣容中。
- 投射命中率先以100次出手的聯盟先驗收縮，再反解現有命中曲線、限制40–99；防守 tracking 以 `D_FGA/(D_FGA+200)` 收縮後反解防守曲線。其他可量測欄位使用 GP≥30、MPG≥20 的同季母體百分位。
- `offBall`、`screen`、`handle`、`breakDbl` 無足夠量測，全部設中性70，不假造個別評分。這會限制真實球隊辨識能力；異質性來自其餘真實來源欄位。
- 固定五人按身高遞增安排 PG／SG／SF／PF／C，身高同分以 AST/min、球員 ID 排序。這是公開的場上職責假設，不是官方先發位置。

## 固定測量協定

引擎使用 `stable-v1`，每方30回合（固定pace100下，每人14.4分鐘等效曝光；不是時鐘模擬）、關閉疲勞、機會籃板模型、固定2025–26聯盟籃板比例，火鍋僅分類既有未進球。正式球權校準另以歷史各隊同季 pace 的36分鐘等效曝光驗證，兩者用途不同。

所有候選都對同一份、等權的30隊池；球隊也包含自身對手，避免各隊排除自己造成對手分布不同。每個對手／槽位具有固定且不同的 seed 序列，各候選共用同一序列；每個 seed 交換 A/B 座位各打一次，和局計半勝。

- 球隊：每個對手128個 seed 配對，`30 × 128 × 2 = 7,680` 場／隊。
- OVR：四名全70平均隊友保持不變，候選輪流替換五個固定位置，各對手／槽位32個 seed 配對，`30 × 5 × 32 × 2 = 9,600` 場／人。
- 25名既有歷史卡與全40／70／99三個錨點接受相同 OVR 協定。卡片費用不進入模擬或映射。
- 另一個固定 seed 對25人各跑4,800場，僅診斷排序穩健性，不重新擬合 OVR，也不保證所有接近的球員排序一致。

seed 配對是**一個**抽樣單位，不能把先後手兩場當作獨立 Bernoulli。以對手／位置分層的均值方差計算標準誤及95%常態近似區間，另附分布無關 Hoeffding 保守區間。正式樣本驗收要求各候選常態區間半寬≤2個百分點、錨點保守區間分離。原始碼、卡表及聯盟資料的雜湊保存於報告；過期的報告不能用來選 PR 對手。

## OVR 與球隊 PR

球員 OVR 由固定基準**勝率**作兩段線性映射：全40球員勝率→OVR40，全70→70，全99→99，再限制0–99並取整數。錨點無嚴格遞增時拒絕映射。淨分差只保留為診斷，不再作 OVR 排序依據。`test/ovr.js` 已改走正式勝率流程，舊淨分差方法保存在 `scripts/legacy_net_ovr.js`，不應用它發布正式 OVR。

這保證同一份估計勝率的映射單調，不是跨任何隊友、對手、賽制或單場結果的強弱保證。區間重疊者不宣稱強弱已確定；整數 OVR 可以同分。OVR 區間以固定估計錨點換算，不涵蓋錨點估計本身的不確定性；錨點區間另列。

球隊依固定池勝率排名，`PR = 100 × (30 − 名次) / 30`，同勝率採中間名次，因此第三名為 PR90。依這個排名選對手，不根據 per36 誤差挑隊。報告的保守名次範圍來自各隊邊際區間比較，**不是同時涵蓋全聯盟排名的95%信賴集合**；PR90邊界附近可能無法分出確切名次。

單項屬性 PR、球員 OVR、球隊 PR 是三個不同量。全屬性94只作極端壓力測試；舊 `per36-pr90` 不重新解讀為真實強隊。

## 重跑

```sh
npm run benchmark:build              # 由已保存官方快照離線建卡
npm run test:strength
npm run validate:strength            # 30隊 + 25名球員 + 3錨點；可從同雜湊 checkpoint 接續
npm run validate:strength-robustness  # 新seed、不重新擬合；附既有費用診斷
npm run per36 -- --team OKC --team-pr 90 --n 1000
# 僅需要更新資料來源時：
npm run benchmark:fetch
```

`--team-pr` 使用已通過驗收且雜湊相符的正式報告，與 `--attribute-pr` 互斥；輸出獨立檔案，並使用相同 stable-v1 規則。per36 的回合曝光不同於30回合排名基準，跨季歷史隊的比較也只是診斷，不能借此宣稱其歷史真實勝率。
