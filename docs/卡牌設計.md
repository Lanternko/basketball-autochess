
# Basketball Autochess 卡牌設計 v0.1

> [!NOTE]
> **範圍**
> 卡片本身：OVR、費用、星級、位置、羈絆、卡面。
> 數值引擎見 [數值模型](數值模型.md)，屬性值見 [隊伍卡表](隊伍卡表.md)。
> **所有數字都是從模擬器推出來的，不是手寫的。**

## 1. OVR 怎麼定義

不用線性加權公式。**把球員放進 PR50 基準陣容取代一名 PR50 球員，量他讓自隊多得、讓對手少得多少。**

```
淨貢獻 = (自隊每回合得分 − 基準) + (基準 − 對手每回合得分)
五個槽位各跑一次取平均（同槽位對位，放哪一格會影響他守誰）
OVR：淨貢獻 0 -> 70（跟屬性尺度同一個錨），全屬性 99 -> 99，全屬性 40 -> 40
```

**這樣做的好處：盯防值 0.221、中投值 0.031 這種權重差異會自動被吃進去**，不必手調任何係數。
zengm 的線性 `ovr` 公式做不到這件事——那也是為什麼它的權重看起來很怪（身高 .159、投籃 .01）。

> [!CAUTION]
> **OVR 明顯偏袒大個子，這是模型的結構問題不是資料問題**
> Hartenstein 83 > Curry 75、Tristan Thompson 79 > Kobe 74。原因可以精確指出來：
>
> **防守改善對手的全部五個回合，得分只改善你自己那 30% 球權。**
> 一個護框者透過 `helpDefense` 的 top-2 合成，一個人就墊高全隊禁區防守；
> 而進攻端的價值是零和的——搶走 PR50 隊友的球權，只賺到效率「差額」。
>
> 已經補了一個對稱機制（**引力**：身邊有超級得分手，隊友出手會變好），
> 後衛平均拉回 2 個 OVR（Curry 73→75、SGA 79→80、Klay 76→77）。**但不夠。**
>
> 我沒有把它硬調到符合直覺——那是把模型擬合到我的先入印象，不是擬合到資料。
> 兩個選項留給你決定：
> 1. **接受**。這就是「這款遊戲的價值尺度」，不是對真實籃球的宣稱。
>    大個子是溢價牌，反制空間就是「怎麼打贏內線」——對自走棋來說是個能玩的軸線。
> 2. **加星度調整**。用真實 DARKO / EPM 排名當外部參照，混一個「牌面」係數。
>    代價是 OVR 不再純粹由模擬推出。

## 2. 費用階梯

**用排名分位而不是 OVR 絕對值。** 現在 25 張全是先發，OVR 擠在 67–89；
卡池擴到含角色球員之後絕對值才會有意義。

| 費用 | 張數 | OVR 區間 | 卡片 |
|---|---|---|---|
| **5 費** | 2 | 87–89 | Durant、Holmgren |
| **4 費** | 4 | 81–84 | O'Neal、LeBron、Hartenstein、Draymond |
| **3 費** | 6 | 77–81 | Towns、SGA、T. Thompson、Love、K. Thompson、Hart |
| **2 費** | 6 | 74–76 | Bridges、Anunoby、Horry、Curry、Iguodala、Kobe |
| **1 費** | 7 | 67–73 | J. Williams、Fox、JR Smith、Dort、Brunson、Fisher、Irving |

> [!WARNING]
> **Curry 是 2 費、Kyrie 是 1 費——這是產品問題不是數值問題**
> 卡牌遊戲的吸引力有一半來自「認得出球星」。上面那張表在數值上自洽，
> 但玩家看到 Curry 跟 Rick Fox 同費會出戲。這跟 §1 的偏袒是同一個根因，同樣兩個選項。

## 3. 星級：加值必須隨費用遞減

三張同名卡合成二星，九張合成三星。加值是**全屬性 +N**（不是乘數——屬性有 SOFT_CAP 150）。

實測（同樣 +12 / +26 全屬性）：

| 卡 | 1 星 | 2 星 (+12) | 3 星 (+26) |
|---|---|---|---|
| Shaq | 84 | 96 (**+12**) | 107 (**+23**) |
| Durant | 89 | 99 (+10) | 108 (+19) |
| Curry | 75 | 82 (+7) | 92 (+17) |
| Fisher | 68 | 76 (+8) | 83 (+15) |

**同樣的加值，高費卡賺更多。** 對自走棋是反的——一費三星必須是一條可行路線。
所以加值要隨費用遞減：

| 費用 | 2 星加值 | 3 星加值 | 三星後的約略 OVR |
|---|---|---|---|
| 1 費 | +16 | +34 | ~88 |
| 2 費 | +14 | +30 | ~90 |
| 3 費 | +12 | +26 | ~93 |
| 4 費 | +10 | +22 | ~97 |
| 5 費 | +8 | +18 | ~100 |

一費三星（~88）打得贏五費一星（~89），但要 9 張——這就是自走棋要的張力。

## 4. 位置：現在是裝飾，應該變成機制

引擎目前是**同槽位硬配對**（A 隊第 i 人守 B 隊第 i 人），跟位置無關。
位置要有意義，最直接的做法是讓它決定對位：

```
兩隊各自按 PG→SG→SF→PF→C 排序，依序配對
位置差 ≥ 2 格 -> 錯位：進攻方取得肉體優勢加成（用該對位的肉體差，不是全隊平均）
```

這一步會讓**五小陣容**變成真正的決策：拿速度換錯位，但被大個子逮到就吃虧。
模型裡已經有肉體差機制，只是現在用的是全隊平均——改成 per-matchup 就成立了。

**未實作。** 這會改動所有已產出的數字（OVR、循環賽），要另開一輪。

## 5. 羈絆：種族 = 時代，職業 = 位置

「種族」照自走棋慣例讀成**出身/流派**這條軸線。用**時代**——
這正好是這個專案的核心（屬性已經 era-normalized，所以不同時代的卡可以公平同場）。

| 種族（時代） | 卡片數 | 觸發 | 效果 |
|---|---|---|---|
| **千禧**（2000s） | 5 | 2 / 4 | 中投 +24 / +48，肉體 +5 / +10 |
| **小球**（2010s） | 10 | 2 / 4 / 6 | 三分 +6 / +12 / +20 |
| **現代**（2020s） | 10 | 2 / 4 / 6 | 傳球 +10 / +20 / +32 |

| 職業（位置） | 觸發 | 效果 |
|---|---|---|
| 控衛 | 2 | 全隊傳球 +10 |
| 分衛 | 2 / 4 | 三分 +6 / +12 |
| 小前 | 2 / 4 | 盯防 +3 / +6 |
| 大前 | 2 | 籃板 +5 |
| 中鋒 | 2 | 協防 +6，肉體 +5 |

### 加成數字是算出來的，不是拍的

用邊際價值表（`node test/marginal.js`）換算成**等功率**。
每個屬性 +1 值多少「每回合得分」：

| 屬性 | +1 的價值 | 給 +0.015 分/回合需要 |
|---|---|---|
| 盯防 | .0044 | **+3** |
| 失誤 | .0031 | +5 |
| 肉體 | .0031 | +5 |
| 籃板 | .0030 | +5 |
| 協防 | .0026 | +6 |
| 三分 | .0023 | +6 |
| 近射 | .0019 | +8 |
| 傳球 | .0015 | +10 |
| 擋拆 | .0014 | +11 |
| 罰球 | .0011 | +14 |
| 無球 | .0009 | +16 |
| 切入 | .0007 | +21 |
| 中投 | .0006 | **+24** |

> [!IMPORTANT]
> **低邊際價值的屬性撐不起羈絆**
> 「+3 盯防」和「+24 中投」是等價的。所以**千禧不能只給中投**——
> 那個數字大到很荒謬，而且中投的價值是條件型的（只對強防守有用）。
> 千禧因此設計成「中投 + 肉體」：肉體扛功率，中投扛時代味道。

## 6. 卡面

```
┌─────────────────────────────┐
│  ⑤   KEVIN DURANT      OVR  │   費用（左上角）· 姓名 · OVR（右上角）
│      SF · 小球 · 2016-17 89 │   位置 · 種族 · 賽季
│  ★★☆                        │   星級
├─────────────────────────────┤
│   進攻      三分 86  中投 97 │   分四組，不是攤平十四個數字
│             近射 99  罰球 96 │
│   創造      切入 84  傳球 86 │
│             失誤 83          │
│   防守      盯防 95  協防 90 │
│             籃板 88          │
│   身體      肉體 83  體力 88 │
│   綜效      無球 84  擋拆 80 │
├─────────────────────────────┤
│  ⚠ 無球/擋拆為手調值         │   資料品質標記（只在有手調時出現）
└─────────────────────────────┘
```

**分五組而不是攤平十四個數字。** 玩家要在兩秒內判斷「這張是什麼牌」，
十四個並排的數字做不到這件事。分組後每張卡有可辨識的形狀。

資料品質標記要保留——湖人 2001-02 有四個手調欄位，玩家有權知道哪些數字比較軟。
