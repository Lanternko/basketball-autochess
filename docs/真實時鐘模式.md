# 真實時鐘模式（timed-v1）

透過 `simulateGame(teamA, teamB, { mode: 'timed', seed: 42, replay: true })` 執行。預設四節各 720 秒，平手時進行 300 秒延長賽。此為新賽制原型，非已校準 NBA 模型。

## 已實作

- 每個動作消耗以十分之一秒為單位的比賽時間，24 秒限制、進攻籃板重設 14 秒；單節結束停止計時。
- 末節領先耗時、落後加速、最後一投、末段故意犯規與追三分；均為明示的啟發式決策。
- 沿用現有能力、隊友情境、傳球窗口、接球選擇、出手品質、籃板與阻攻模型。沒有引用第三方遊戲程式碼。
- 球員名單可超過五人；前五名健康球員先發。死球與節間依體力、累計分鐘缺額、能力與位置輪替。`targetMinutes` 可指定 0–48 的輪替目標，是偏好而非保證。預設先發 32、替補 16，未正規化目標到 240，建議正式名單自行設定合理目標。
- 球員在場消耗體力、板凳恢復；`injured:true` 的球員不出賽。輸入名單不被修改。
- 投籃犯規兩／三罰、and-one、非投籃犯規、團隊加罰、末兩分鐘犯規、犯滿替換；不足五人時保留犯滿球員並罰技術罰球。沒有完整技術／惡意犯規類型。
- 罰球停錶；最後一罰不進且節未結束可搶籃板。罰球籃板機率是獨立暫定值，不聲稱已從資料估計。
- 命中且選擇接球出手時計上一位傳球者助攻，自行再創造、罰球與補籃不沿用前次助攻。
- 可重現 seed；是否記錄 events 不影響結果。事件球員索引指向完整 roster，lineups 保存當下場上索引。

## 輸出與執行

`statA/statB`、`playersA/playersB` 包含分鐘、PTS/FGA/FGM/3PA/3PM/FTA/FTM、攻守籃板、AST/STL/BLK/TOV/PF。`gameSeconds` 是實際走過的比賽時間，`periodScores` 是各節得分。`poss` 是開始的球權，包括節末無出手球權，不能冒充官方回合數。

最多預設 20 次延長賽；若仍平手，回傳 `complete:false`、`termination:'overtimeLimit'`、`winnerA:null`。批次工具必須排除或另外處理未完成賽事，不能硬算敗場。

`npm run test:timed` 執行結構與回歸測試；`npm run benchmark:timed` 產生合成十人隊的 100 場報告及現有五人歷史卡的完整事件範例。

舊 `monteCarlo` 的統計欄位及固定五人語義不適用 timed，會拒絕 timed 選項；批次請直接呼叫 `simulateGame`（參考 benchmark script）。既有 fixed/race 預設與 seed 輸出不變。

## 尚未涵蓋

暫停與暫停前場發球、進攻犯規、八秒與完整違例、比賽中傷病、實際傳球路徑、十人座標與球飛行時間尚未實作。出手在出手時間立即抽樣結果，沒有跨蜂鳴器球飛行模型。先發／替补採位置加分，沒有全陣容位置最佳化。

能力與出手機率仍來自舊模型，其中犯規 EV 原先按兩罰估計；本階段沒有重校準為三罰／and-one 的完整決策 EV。正式 NBA 30 隊 82 場驗證前，還需完整名單、賽程、出勤、共同基準與數值校準。

既有 courtside 頁面仍為短局動畫回放；timed 的事件名稱、完整名單索引與時鐘要完成對接後才能切換，不能只改 mode 就宣稱已有 48 分鐘觀戰。

規則參考：[NBA 計時](https://official.nba.com/rule-no-5-scoring-and-timing/)、[進攻時間](https://official.nba.com/rule-no-7-24-second-clock/)、[犯規與罰則](https://official.nba.com/rule-no-12-fouls-and-penalties/)。規則預設與原型機率假設分開；未宣稱完整 NBA 規則相容。
