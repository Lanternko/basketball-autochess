# 觀賽介面

在專案根目錄執行 `python scripts/serve-ui.py`，開啟 http://127.0.0.1:5173 。數值實驗室仍位於 `calculator.html`。

## 畫面與操作

- 桌面觀賽區固定 16:9，依視窗高度縮放；同時保留全場、兩隊比分與隊名、左右各五張頭像、播報及播放控制。
- 場上十人為穿主客隊色球衣的 SVG 關節小人物。背號 1–5 為陣容辨識編號，並非歷史球衣號碼；臉部仍是通用造型。左右頭像使用本機真人照片。
- 點選人物或左右頭像追蹤球員。完整數據與事件紀錄預設收合，按「數據與紀錄」查看。
- 播放／暫停、1–8 倍速、下一事件、拖曳進度、重播、新比賽、全螢幕。
- 每隊固定 50 次進攻。上方倒數是 **1× 回放剩餘時間**，不是比賽時鐘；旁邊顯示進攻次數。倍速會加快倒數，暫停會凍結。
- 窄螢幕重排控制列，保留兩側陣容；支援鍵盤、照片缺圖備援與減少動態效果偏好。

## 動畫與球路

`src/court-scene.js` 是可獨立測試的呈現模型。每個事件計算 start/end 人物座標、球的 x/y/高度與落點。前一事件完整終態就是下一事件的起點，預先產生的終態也讓跳轉與重播保持一致。

- 換球權：十人跑動到另一側，跑步時四肢交替擺動；持球者運球，防守者展臂對位。
- 投籃／上籃：抬手與起跳，球沿含高度的弧線到籃框；到框才結算。
- 命中：穿框落地並帶動球網伸縮。
- 未進／封阻：球反彈至依下一個籃板事件選定的區域；籃板球員移動、起跳接球、收球落地。
- 抄截：防守者靠近持球者伸手，球連續轉移到抄截者。
- 球旁投影與地面人物投影是空間提示；已取消額外的大型動作剪影與預畫球路虛線。

`src/player-pose.js` 提供關節插值，`src/player-figure.js` 畫出球衣、頭部與四肢。`src/court-motion.js` 以同一條 requestAnimationFrame 時間軸驅動人物、球、球網、倒數和數據結算。暫停凍結當前影格，倍速縮放整條時間軸。減少動態效果下直接呈現各事件終態，事件之間讓出動畫影格避免同步遞迴。

## 播報與資料

數據只由 `simulateGame(..., {replay:true})` 的事件快照決定。動畫不消耗模擬亂數、不修改機率或終場結果。`eventHighlights` 比較相鄰快照，結果接觸點在當事人物旁出現「得分 +2」「抄截 +1」「籃板 +1」等短提示。下方只保留一句事件播報，累計數據留在側邊與展開表格。

STEAL 歸屬 defender；阻攻依 blocker 名稱尋找真正防守者；DREB 的 off 為搶板隊。FOUL 後逐球播放 FTM/FTX，未進不加分。抄截同時顯示守方抄截與攻方失誤，但不以長卡片遮擋球場。

本版仍是事件驅動的動作演出，並非碰撞或戰術 AI；固定五人、無替補、無犯滿離場、無真實節次與時間制。灌籃是部分 RIMM 的呈現分類，不是新增得分結果。

## 驗證

```powershell
node test/court-scene.js
node test/motion.js
node test/replay.js
node test/event-highlights.js
npm test
```

Scene 測試覆蓋三個 seed 的全部事件起終點連續、球路分段接點、籃板落點、暫停取樣決定性與回放倒數邊界。其餘測試維持回放與模擬結果一致、得分守恆、數據歸屬及本機頭像完整性。

照片來源記錄在 `assets/players/sources.json`；拍摄年份與球衣未必對應陣容所標賽季。
