# v49 輪替：分鐘、時段與同場搭配

輪替已通過四季的採用條件。後續量測修正以 v49 輪替為基礎，使用 `reports/player-impact-v49/input.mjs` 與 `reports/player-impact-v49/engine.mjs`；它保留 v47 的全部球員能力、進攻及防守機率設定。v48 的出手選擇候選未合併。

新控制器依本場分鐘目標追蹤缺口，並利用排除被測比賽整折的歷史資料，估計各節上場分布及隊友同場關係。不再以能力分數決定誰補上。保留官方先發、每場既有出賽名單與分鐘總額作重建條件；這不是未來分鐘預測，也不是直接重播該場實際換人。

處理包括最短一般上場／休息段、短暫出場的分鐘上限、節間休息、最後階段的剩餘分鐘可行性、罰球投籃人保護及犯滿替換。換人仍使用既有死球時點。加時沿用原啟發式；極少數人手不足五名的犯滿情境沿用原最低五人處理，額外技術犯規事件尚未新增。

四季等權平均，單位為分鐘：

| 誤差 | v47 | v49 |
|---|---:|---:|
| 每次出賽實際分鐘 MAE | 1.557 | 1.004 |
| 正規時間目標 MAE | 1.432 | 0.857 |
| 上場時段絕對差之和／每次出賽 | 18.945 | 15.052 |
| 每組隊友每場同場時間 MAE | 4.021 | 3.168 |
| 球隊場均得分 MAE（分） | 2.323 | 1.977 |

2025–26 共同 PBP 場次的正規時間：Payton II 與 Curry 同場實際 413.77 分鐘，模擬從 214.19 提升至 278.97；Curry 下場時實際 53.89，模擬從 305.03 降至 197.55。方向已改善，殘差仍大，不能聲稱這組搭配已完全準確。

短上場段仍比來源多；2025–26 的上場段中位數從舊版 207.6 秒提升至 273.4 秒，來源為 370 秒。個人得分／36 MAE 從 0.736 增至 0.799，外線防守命中率 MAE 也未達原訂回歸門檻，因此**只採用輪替開發基準，整體進攻基準仍為 v47**。下一個進攻候選應基於 v49 輪替重新檢查投籃人與出手分配，避免恢復錯誤輪替來維持舊誤差。
