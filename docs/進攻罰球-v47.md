# v47：進攻第一步，修正罰球準度

v47 已完成四季、三種子、24 組共 28,023 場驗證，採用為後續量測模型的進攻開發基準；防守係數沿用凍結的 v46。遊戲既有預設及 OVR 排行沒有切換。

舊罰球轉換以固定 100 次先驗收縮，再由能力卡的 40–99 範圍壓成 56%–90%。獨立重建四季全部 2,581 個球員在隊條目，都精確符合這個公式。新版本另外保存量測罰球機率，使用較早三季整場五折交叉驗證選出的 20 次共同先驗；不是針對 Curry 加成。卡面 ft 不改，後續 ft 屬性改變仍會影響罰球機率。

| 四季平均 MAE | v46 | v47 |
|---|---:|---:|
| 個人罰球命中率，百分點 | 3.1438 | 1.8406 |
| 球隊每場得分，分 | 2.4021 | 2.3232 |
| 在場對手禁區命中率，百分點 | 1.0484 | 1.0706 |
| 在場對手三分命中率，百分點 | 1.2387 | 1.2159 |

四季的個人罰球 MAE 全部下降，12 組同季同種子的比較也全部改善。球隊得分四季平均改善，但 2023–24 MAE 從 2.6474 增至 2.6953 分；禁區命中率誤差也略增。防守係數未變，不代表完整比賽結果必須完全相同；罰球結果會改變後續球權、輪替及亂數路徑。完整粗區、細區與位置分組結果都有保留。

2025–26 Curry：實際罰球 92.31%，v46 模擬 86.60%，v47 90.44%。每 36 分鐘得分從 29.81 到 29.97，仍低於實際 30.94。不能把罰球改善當作整個進攻問題已解決。

下一階段以 v47 為比較基準，處理出手量與隊友兩分進攻。Curry 在場隊友兩分命中率仍是 58.15%，實際 60.78%；不在場球隊兩分命中率則是 58.02%，實際 52.77%。這個相反方向的偏差值得追查，但原始 on/off 仍含隊友、對手及輪換差異，不能直接當成姓名加成。需要拆開禁區及中距離、投籃者及陣容，再評估共用空間機制；不能全面提高 Curry 三分命中率。
