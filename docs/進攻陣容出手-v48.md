# v48 進攻陣容出手測試

v48 已完成四季、三種子、full／strict 共 24 個工作與 28,023 場模擬。尚未採用，量測進攻開發基準維持 v47；防守基準維持 v46。遊戲預設與 OVR 不變。

本候選只改新鮮兩分出手的籃下／其他油漆區／中距離分配，聯合估計投籃人和另外四名隊友的條件係數。較早三季整場五折驗證選擇共用正則化，2025–26 未參與參數選擇。所有命中率、三分選擇、罰球及防守係數保留。

四季平均隊友兩分命中率 MAE 從 1.3049 降為 1.2455 個百分點；隊友籃下占兩分出手的 MAE 從 2.0514 降為 1.4409 個百分點。但球隊 PPG MAE 從 2.3232 增為 2.3532，未達事先列出的不退步條件，因此保留候選而不切換基準。

Curry 隊友的出手區域更接近來源，命中率仍有偏差。三種子觀測且全部個人／團隊結果與 v47 相同的診斷確認：2025–26 共同場次裡，Payton II 與 Curry 實際同場約 414 分鐘，模擬約 215；Curry 下場時則實際約 54、模擬約 305。換人使用每場分鐘目標，並不保證實際同場組合；每 36 分鐘的條件出手率也仍有偏差。下一步優先修通用同場輪替，再處理剩餘空間及投籃人分配，不能讓能力係數補償錯誤陣容。
