# 防守五區候選 v45

本輪完成全員共用的五區防守與出手分布模型，並完成 2022–23 至 2025–26、三種子、24 組共 28,023 場模擬。沒有 Wembanyama 姓名特例。逐球的分區火鍋曝光通過較早三季整場留出選擇；上一季最近防守者追蹤特徵未勝出，沒有強行納入。

2025–26 Wembanyama 在場的對手禁區命中率為 50.49%，真實 50.58%，v44 為 53.91%。禁區出手占比 on/off 差距由 v44 的 −1.06 改善至 −5.39 個百分點，真實 −6.34。但下場時的限制區防守被估得太差，仍放大他的護框 on/off 效果；其他油漆區出手抑制與中距離命中率也未修準。

**v45 尚不升為正式模擬或 OVR 基準。** 四季平均的全體禁區防守命中率 MAE 從 v44 的 1.2048 增至 1.3629 個百分點，四季均退步；三分則由 1.4149 改善至 1.2514。球隊得分 MAE 四季平均 2.3335 → 2.3695 分，目標季 2.1690 → 2.0701 分。使用者已允許短期球隊退步，本次保留為候選的主因是個人禁區防守的廣泛退步。

固定真實陣容與出手的交叉驗證同樣出現合併禁區 MAE 退步，不能只怪模擬亂數。下一步應以較早三季比較共用禁區效果與細區偏移的收縮，並分開量測細區進攻基準、防守活動與輪替的影響。不能只因 Wembanyama 或逐球似然改善就採用。

五區投射分布已接入，但犯規與籃板仍依三區處理。總出手率威懾尚未獨立辨識。這些結果是已看過賽季的重建，不是未來預測或個人因果防守。本輪未重算 582 人 OVR。
