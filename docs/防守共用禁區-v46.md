# v46：接續 v45 的防守基準

防守階段已正式收束。最後完整性核對通過；採用範圍、保留問題與證據雜湊見 [收束紀錄](../reports/player-impact-v46-closeout/report.md)。後續進攻工作另建 v47，目前的 [Curry 四季進攻診斷](../reports/player-impact-v47/diagnosis.md) 沿用凍結的 v46，尚未改動進攻係數。

v46 保留 v45 的五區資料、出手選擇與量測，將限制區和其他油漆區的防守效果聯合估計為「共用禁區效果＋細區偏移」。無姓名特例；以較早三季的整場交叉驗證選擇收縮，2025–26 不參與選模。選擇目標優先符合球員數據誤差，逐球細區似然略退步也有保留揭露。

四季、三 seed、24 組共 28,023 場模擬後，全體在場禁區命中率 MAE 從 v45 的 1.3629 降到 1.0484 個百分點，亦優於 v44 的 1.2048，四季均改善。三分命中率 MAE 為 1.2387；後衛、前鋒與中鋒的平均禁區誤差都下降。球隊得分 MAE 四季平均從 v45 的 2.3695 增至 2.4021 分，依使用者先修防守的授權接受並保留追蹤。

2025–26 Wembanyama 在場的對手禁區命中率為 50.745%，真實 50.576%；禁區命中率 on/off 差距為 −6.634 個百分點，真實 −6.511。但限制區與其他油漆區的個別 on/off 仍有相反偏差，不能把合併數字接近當成全部修準。

v46 **採作下一版球員防守開發的基準**，後續應由這裡繼續，而非退回 v44 或強行採用 v45。這不表示遊戲既有預設或 OVR 排行已切換；本輪沒有重新計算 582 人 OVR。總出手率威懾、細區犯規與籃板幾何仍待獨立處理。
