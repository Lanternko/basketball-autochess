# 防守第一批結果

2026-10-12。第一批完成：新增獨立 `nba-defense-v1`，保留原版基準；30隊各82場、四組seed的完整回溯報告，以及八種條件的完整賽季拆解。

## 修正與資料

取得1230場NBA官方box score的先發、位置、逐場上場秒數及30隊進階資料，保存來源與雜湊。正式回溯模式使用官方出賽者、先發與分鐘軟目標，保留疲勞、正常六犯離場及死球／節間輪替。這限制了傷病與出賽差異，但尚未重現真實換人時段；同季資料已知，不能當季前預測。

確認並修正投籃犯規的條件機率錯誤：真實FG%已排除犯規投失，原引擎先以該FG%抽命中、再排除犯規投失，造成記帳FG%偏高。例如原始50%命中與10%犯規機率會記成52.63%；現在先逆推抽樣機率，讓記帳結果回到目標。

失誤壓迫改由收縮後STL／分鐘訊號約束，與三分投射干擾分開。既有失誤拆成活球／死球並歸屬抄截，不額外添加失誤；持球抄截目前只有分類記帳，反擊狀態仍待實作。進攻機會改採在隊觀測出手量權重，三分與近射情境係數分開校準。沒有球隊ID或真實勝場補丁，沒有修改球員OVR。

## 正常輪替的結果

以下前後同為seed 20261012、完整1230場。新版本同時含上述多項修正，不能把全部改善都歸因於其中一項。

| 指標 | 原版 | 防守v1 | 真實 |
|---|---:|---:|---:|
| FG% | 52.64 | 47.40 | 47.10 |
| 3P% | 40.86 | 36.53 | 35.96 |
| 2P% | 60.91 | 54.91 | 55.00 |
| STL／場 | 2.58 | 7.42 | 8.42 |
| TOV／場 | 14.24 | 14.45 | 14.51 |
| PPG | 116.34 | 117.16 | 115.61 |
| 30隊防守效率代理MAE | 10.46 | 3.02 | — |
| 30隊勝場MAE | 8.13 | 7.27 | — |
| 雷霆勝場 | 46 | 51 | 64 |

效率代理以雙方 `FGA−OREB+TOV+0.44FTA` 的平均作分母，真實與模擬同口徑；不是官方DefRtg。原版PPG雖接近真實，命中率與球權卻同時有偏差，不能只用得分判定準確。

四組正常輪替seed的FG%為47.33–47.44，3P%為36.53–36.76，防守效率代理MAE為2.81–3.12，勝場MAE平均7.05場。逐場球員分鐘MAE平均1.40分鐘；這是軟目標下的誤差，並非分鐘完全相同。

用其他條件相同的正常輪替版本，只切換犯規抽樣修正，四組seed的防守效率代理MAE均從7.42–7.93降至2.81–3.12。這支持修正該機制；不同seed只能支持隨機穩定性，不能替代時間切分的資料外驗證。

## 雷霆與下一階段

雷霆四組seed為46、48、51、52勝，仍不足以還原真實64勝。seed 20261012場均失分117.27，真實107.88，仍多9.39分；對手2P%為53.11%，真實49.14%；STL／場8.29，真實9.71；迫使TOV／場14.78，真實16.73。

全局命中率已大致對齊，雷霆殘差仍大，表示接下來需重建球隊與陣容間的防守差異。單靠全局參數或增加抄截記帳不能完成這件事。下一批依序補強：

1. 官方逐球事件與換人：重建場上五人和真實陣容區段，對照先發／替補、防守時段與球員正負值，分離分鐘曝光和能力問題。
2. 真實活球失誤與反擊：驗證失誤類型、壓迫量、耗時與轉換得分，避免STL提高卻沒有相應比賽影響。
3. 對齊護框與出手區域：6呎內防守不能直接代表所有油漆區；補被防守出手量及對位責任，再檢查30隊防守排序。
4. 跨季／時間切分驗證：建卡只使用截止日前資料，校準與測試分開；之後才以陣容調整後的正負值檢查球員高估／低估，不能直接用原始正負值改OVR。
