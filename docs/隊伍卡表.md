
# Basketball Autochess 隊伍卡表 v0.4

> [!NOTE]
> **用途**
> 五支測試隊 × 五人，十六屬性——十三項由真實 NBA 資料逆推，
> 三項（無球／持球／破包夾）手填並對齊真實 USG%。
> 給 [數值模型](數值模型.md) 的 OVR 計算器當輸入。
> v0.4 新增 **傳球 / 罰球**，並修正失誤的分母。

## 映射方法

每名球員在**自己那個賽季**的 rotation player 母體（G ≥ 30、MPG ≥ 20）內取百分位，
再依 `pr1→40 / pr50→70 / pr99→99` 分段線性映射。

**在自己的賽季內取百分位 = 自動 era-adjusted。**

| 屬性 | 來源欄位 | 端點 |
|---|---|---|
| **三分** | Corner 3 + Above the Break 3 的 FG% | leaguedashplayershotlocations · By Zone |
| **中投** | Mid-Range 的 FG% | 同上 |
| **近射** | Restricted Area + In The Paint (Non-RA) 的 FG% | 同上 |
| **罰球** | `FT_PCT`（低量用 log(FTA) 迴歸當先驗） | leaguedashplayerstats · Base |
| **切入** | `0.5×z(FTA/FGA) + 0.5×z(禁區出手佔比)` | Base ＋ 上表 |
| **傳球** | `AST_PCT` | leaguedashplayerstats · Advanced |
| **失誤** | `TOV/(FGA + 0.44×FTA + AST + TOV)` 反轉 | leaguedashplayerstats · Base |
| 籃板 | `REB_PCT` | leaguedashplayerstats · Advanced |
| 盯防 | `PLUSMINUS`（反轉） | leaguedashptdefend · **3 Pointers** |
| 護框 | `PLUSMINUS`（反轉） | leaguedashptdefend · **Less Than 6Ft** |
| 體力 | `MIN`（MPG） | leaguedashplayerstats · Advanced |
| 肉體 | `0.45×z(身高) + 0.55×z(體重)` | leaguedashplayerbiostats |
| 無球 | `CATCH_SHOOT_FG3A` | leaguedashptstats · CatchShoot |
| 擋拆 | `SCREEN_ASSISTS` | leaguehustlestatsplayer |

**逆推的十三項裡有十項只需要 box score、shot locations 或身高體重，1996-97 起零斷層。**
只有無球、擋拆、盯防、護框四項依賴 tracking / hustle。

> [!CAUTION]
> **失誤的分母必須含助攻，否則傳球者被系統性懲罰**
> 官方 TOV% 的分母是 `FGA + 0.44×FTA + TOV`——**不含助攻**。
> 傳球者用球的次數大部分沒被算進去，於是「會傳球的人失誤多」變成一個假相關：
>
> | 賽季 | corr(AST%, 官方 TOV%) | corr(AST%, 含助攻 TOV%) |
> |---|---|---|
> | 2001-02 | +0.39 | −0.03 |
> | 2015-16 | +0.49 | +0.20 |
> | 2016-17 | +0.53 | +0.25 |
> | 2025-26 | +0.51 | +0.33 |
>
> 修正後：Draymond 失誤 2.2 → **12.4**、Iguodala 59.1 → **84.9**、Curry 37.3 → 48.0。
>
> **這也是「傳球與控球不該合併」的證據**：即使修正後兩者仍是正相關（傳球多的人
> 失誤確實比較多），合併成單一「控球」屬性會讓 Draymond（傳球 91 / 失誤 47）
> 變成平庸的控球者——兩個訊號互相抵消。

> [!IMPORTANT]
> **「沒出手」不等於「聯盟平均」**
> 用經驗貝氏往聯盟均值收縮，會讓整季只出手 1 次三分的 Shaq 拿到 **pr 50.5**。
> 改成用 `log(出手數)` 迴歸命中率、把**迴歸線**當先驗：
> Shaq 三分 **pr 8.1**、Tristan Thompson（整季 0 次三分）**pr 0**、Hartenstein **pr 4.8**。
> 同一招用在罰球上：**Shaq 的 FT% .555 是 pr 1.0 → 罰球屬性 40**，Hack-a-Shaq 成立。

> [!WARNING]
> **臂展缺席**
> 臂展只有選秀體測有、且不是每人都測。目前只用身高 + 體重，長臂型球員會被低估。

## 球權還原度

真實值取自 `stats.nba.com/stats/leaguedashplayerstats?MeasureType=Advanced`，各自賽季。
模型只打先發五人，所以每隊正規化到 100——真實五人加總 106–111%，
差額是板凳吃掉的球權，那不在這個模型的範圍內。

> [!IMPORTANT]
> **手填三欄是對齊出來的，不是獨立來源**
> 無球／持球／破包夾沒有 box score 欄位對應得上，逼近方式是有界座標下降 +
> 正則化，目標函數就是上面那張表。**這是輸出對齊，不是獨立驗證**——
> 用它證明模型正確會是循環論證。
>
> 但擬合器跑出沒有籃球意義的值時一律不採用：SGA 的持球被壓到 67、
> Durant 壓到 56、Hartenstein 拉到 63，全部退回。
> 靠把 Draymond 的持球灌到 57 才對得上真實數字，那是把答案寫進輸入。

## 已知偏誤

> [!WARNING]
> **出手區域佔比是現代校準的**
> PR50 基準是 2025-26 的 .483/.110/.407，所以湖人 2001-02 不會投出當年的 .378 中距離。
> **屬性算得到，時代打法算不到。** 這是刻意的——自走棋要讓不同時代的卡在同一套規則下比。

> [!WARNING]
> **防守 PLUSMINUS 會高估被藏起來的球員**
> 教練會把弱防守者藏在對方最差的進攻點上。Curry 盯防 58 / 護框 44——後者符合直覺，前者偏高。

> [!WARNING]
> **擋拆分布極度右偏**
> pr50 .39 次/場、pr99 3.68 次/場，中鋒壟斷。目前直接線性映射，應改 log 或分位置定錨。
