# 發現帳本（findings）

關於模型、資料、球員、程式的事實。讀寫規則見 [README.md](README.md)。

欄位（固定）：
- **ID**：`F-001` 起，只追加。
- **日期**：發現或量測的日期。
- **說法**：一句話。
- **證據**：指令、檔案路徑、報告、數字。
- **狀態**：`已證實`｜`被推翻`｜`待驗`。改狀態時在括號註明日期與原因。已知限制、還沒修的、建議未做的都記成 `待驗`（說法開頭寫「未修：」或「建議未做：」）。
- **相關**：其他 ID。
- **來源**（選填）：commit、報告或對話。

範例：

```
### F-999
- 日期：2026-10-28
- 說法：遊戲本身沒有讀任何 OVR。
- 證據：追查資料流，commit 5e6cb4d。
- 狀態：已證實
- 相關：E-018
```
