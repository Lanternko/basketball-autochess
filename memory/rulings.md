# 裁決（rulings）

使用者對球員評價、驗收方式、流程的裁定，以及籃球規則與硬規則。卡片、模擬與驗收不得違反。讀寫規則見 [README.md](README.md)。

欄位（固定）：
- **ID**：`R-001` 起，只追加。
- **日期**
- **裁決**：一句話。
- **細節**：適用範圍、例外、怎麼做。
- **理由**
- **狀態**：`有效`｜`暫定`｜`已廢止`。改狀態時括號註明日期與原因。
- **相關**：其他 ID。
- **來源**：誰說的、對話日期或 commit。

範例：

```
### R-999
- 日期：2026-10-27
- 裁決：OVR 可以超過 99，也可以低於 40。
- 細節：驗收不用固定範圍。
- 理由：正式卡本身是 38.1–109.9。
- 狀態：有效
- 相關：L-013
- 來源：使用者 2026-10-27
```
