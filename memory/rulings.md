# 裁決（rulings）

使用者對球員評價、驗收方式、流程的裁定，以及籃球規則與硬規則。卡片、模擬與驗收不得違反。讀寫規則見 [README.md](README.md)。

欄位（固定）：
- **ID**：`R-001` 起，只追加。
- **日期**
- **裁決**：一句話。
- **細節**：適用範圍、例外、怎麼做。
- **理由**
- **狀態**：`有效`｜`暫定`｜`已廢止`。改狀態時括號註明日期與原因。
- **相關**：其他 ID。
- **來源**：誰說的、對話日期或 commit。

範例：

```
### R-999
- 日期：2026-10-27
- 裁決：OVR 可以超過 99，也可以低於 40。
- 細節：驗收不用固定範圍。
- 理由：正式卡本身是 38.1–109.9。
- 狀態：有效
- 相關：L-013
- 來源：使用者 2026-10-27
```

### R-025

- 理由：使用者「OVR依照定義就是 擺上四個平均隊友 能帶來多少比賽影響力，這個是目標。」

### R-027

- 裁決：「接戰場分鐘」（用接戰場的場均上場時間取代整季 MPG）列為待辦，不擋每場 OVR 先上線。基準使用者傾向副版（替補水準），上線前再確認。
