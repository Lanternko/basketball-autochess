## 3. 指標
- 檢查點 N ∈ {0, 5, 10}：用前 N 場（N＝0 即 x0）算賽中 OVR。
- **答案**：第 N+1 到 N+20 場的 20 場視窗卡（照 E-139 `answer_cards`）。答案**不得**依賴候選 s：答案側若要用到新秀起點（假上季卡、凍結屬性），一律用 B0r（−5）的 x0；c0a 檢查。
- J＝三個檢查點絕對誤差的平均（每人先平均，再對人平均）。
- 偏差＝（預測 − 答案）的平均，分全部、第 1–10 順位、11–30、31 以後與落選。

## 5. 選擇與判定
1. **訓練選 s***：在 B0r、S25、S0 中取訓練四季合併 J 最小者。J 差 < 0.05 算平手，取扣分較多者（−5 優先，再 −2.5）。
2. **測試**：D1＋D2 只跑 s*、B0r（S0、S25、S+25 也輸出但不判定）。以球員為單位配對 bootstrap 2000 次，seed 1，90% 區間取第 5／95 百分位。

| 判定 | 條件 |
|---|---|
| **採用候選** | s* ≠ −5，且 ① 測試 J(s*) − J(B0r) 的 90% 上界 < 0；② 第 1–10 順位的 J 不比 B0r 差（點估計）；③ 落選與 31 順位以後的平均偏差 s* 不比 B0r 更偏高超過 +3 |
| **維持 −5** | s* ＝ −5，或 ①②③ 任一不成立 |
| **只報告** | c0n 人數不足 |

- 採用候選 → role-audit 重算 → 使用者 G5 看 2026 屆換版前後名次（含 Boozer、Lendeborg、Flagg 型頂順位與晚順位防守型）→ 上線（只改 `build_2k_start.py` 的位移常數，重產 `rookie-prior-2026.json`）。
