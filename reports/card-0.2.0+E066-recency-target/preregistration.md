# E-066 預註冊：卡片能力值的近期加權與小樣本收縮目標

- 日期：2026-10-29（使用者「寫預註冊」；裁定 R-029、R-030）
- 版本：`card 0.2.0+E066`（R-018）。版本號在使用者看完結果後再定。
- 基準：`card 0.2.0`（`reports/card-0.2.0/`）。能力值收縮沿用 card 0.1.1 起的 E-055 方法 (c)（`reports/ovr-v61-shrink-history-2025-26/`）。
- 角色：role-card 實作並跑回測；判讀由 lead 做，數字由 role-audit 另外重算。

## 1. 問題（lead 已看過的東西，已揭露）

E-055 的收縮公式（`engine.py:186`）：

- rate = (n1 + k·T)/(d1 + k)
- T = (Σⱼ λ^(j−1)·nⱼ + kh·m)/(Σⱼ λ^(j−1)·dⱼ + kh)，j 取前 1–3 季
- m 是聯盟平均或同位置平均

這個公式有兩個問題：

- **整季等權。** 同一季裡每一場的權重都一樣。
  - Jared McCain 2025-26：費城 37 場 TS .506、每 36 分鐘 14.2 分；雷霆 30 場 TS .593、20.9 分。
  - 卡片 57.9。使用者把他排在 2026 雷霆第 8（R-029）。
- **沒有歷史的人往聯盟平均拉。** 沒有前三季資料時，T 退回 m；drive 沒資料時固定給 70。
  - card 0.2.0 裡，MIN<100 的 79 人每 36 分鐘 OVR 中位數是 65.8，比 MIN 100–1000 的各組（62.5–62.9）都高。
  - Nikola Topić（160 分鐘，2024-25 整季傷停）59.7，排在 McCain 前面。
  - 使用者裁定這是高估，目標要依人而定（R-030）。

lead 看過的資料：

- card 0.2.0 的 ranking.csv；
- McCain、Topić、雷霆輪替的 box score 與 RAPM；
- 上面的 MIN 分組中位數；
- E-055 已公開的回測數字。

**任何候選版的回測數字都還沒看過。**

## 2. 共同框架（沿用 E-055 回測，寫死）

- 回測：用「前面各季＋該季上半季」預測「該季下半季」的比率。
  - 上半季＝依日期排序的前 574/1230 場。
  - 八個屬性：ft、foulDraw、tovSkill、pass、rebound、mid、short、drive（drive 分成量與質兩部分）。
  - 每個屬性的季別、分母門檻 `MIN_D2`、替代分母都照 `backtest.py` 不改。
- 擬合：k、λ、kh 用 `K_GRID`、`LAM_GRID`、`KH_GRID`，只在 2025-26 以前的季上最小化 MAE。每個候選都用自己的設定重擬合；這是程序的一部分，不是看結果調參。
- **選候選只看擬合季**：同一題的幾個候選，用擬合季的合併相對 MAE 選一個，之後只在測試季判定一次。這和 E-055「看測試集選」不同，是刻意改的。
- 測試季：2025-26。
- 合併相對 MAE：每個屬性 MAE(候選)/MAE(現行) − 1，八個屬性等權平均；drive 用 E-055 的組合誤差。
- bootstrap：以球員配對重抽 2000 次、seed 1。

## 3. A 題：同季近期加權

### 3.1 候選（寫死）

上半季每一場的 n、d 乘上權重 w_g = 0.5^(a_g/H)。a_g 是該場到觀測期最後一天的日數。歷史季的 λ 不變。

| 候選 | H（天） |
|---|---|
| A0（現行） | ∞ |
| A60 | 60 |
| A30 | 30 |

- 權重縮小以後，有效樣本 Σw·d 跟著變小，收縮會自動變強。這是預期中的行為，不另外補償。
- 套到卡片時，用 2025-26 全季、以該季最後一場為基準日的同一組權重。

### 3.2 判定

- 在擬合季的合併相對 MAE 上選 H\*。H\* 是 ∞ 時，A 題記為「不採用（擬合季選現行）」，不看測試季。
- 測試季：
  - **(A1) 變準**：合併相對 MAE 差的 90% 區間上界 < 0；
  - **(A2) 不比現行差**：每個屬性相對 MAE ≤ +1%。
- 只報告：
  - 季對季檢查：用 H\* 加權的 s 季全季，預測 s+1 季上半季，只看 box 類五項、s = 2015-16..2024-25。另外把 s 季中途換隊的人單獨列出，這是 McCain 型案例。
  - 上半季內換隊的人數（預期很少，因為交易截止日在下半季）。

不另設「交易後加權」候選：主框架的測試季上半季幾乎沒有換隊的人，驗不出來。交易案例只看上面的季對季檢查。

## 4. B 題：小樣本收縮目標依人而定

### 4.1 候選（寫死）

把收縮目標 m 換成依上場時間分組的條件平均。kh·m 項和沒有歷史時的退回值都用新的 m。

- MPG 分組依觀測期的 MIN／GP 切成 <12、12–20、20–28、≥28。
- 組平均依出手或機會加權，和現行 m 的算法相同，在同一季同一觀測期內計算。

| 候選 | m |
|---|---|
| B0（現行） | 聯盟平均或同位置平均（E-055 的選法） |
| B1 | 球員所在 MPG 組的平均 |
| B2 | MPG<12 組的平均，所有人都用這組（「往聯盟底層拉」） |

- B1、B2 各自照 E-055 的規則，用擬合季 MAE 在「只分 MPG 組」和「位置×MPG 組」之間選一個。位置×MPG 組的觀測不到 20 人時，併回只分 MPG 組。
- drive 沒有資料時固定給 70 的規則，改成所在 MPG 組 drive 屬性值的中位數（B2 用 MPG<12 組）。
- onBall／help：實作時先查有沒有固定中性值的退回規則。有的話，列出人數並照 drive 的規則改；沒有的話，這一項不做，並在報告裡寫明。

### 4.2 判定

先在擬合季的合併相對 MAE 上，從 B1、B2 選一個 B\*。

| # | 條件 | 門檻 |
|---|---|---|
| (B1) | 目標族群變準 | 測試季「沒有前三季歷史」的人（Σd_hist = 0，而且下半季分母達 `MIN_D2`），合併相對 MAE 差的 90% 區間上界 < 0 |
| (B2) | 全體不變差 | 測試季全體合併相對 MAE ≤ +0.5% |

- 這個族群的人數若有任一屬性 < 30，就記為「樣本不足」，只報告，不判定。
- 只報告：
  - 擬合季未選上的那個候選在測試季的數字；
  - 依 MPG 組的有號平均誤差（看現行版在低分鐘組是否系統性高估）。
