## 0. 假設

卡片裡所有讀 RAPM 的步驟都用四季（2022-23..2025-26）等權合併的 RAPM（`reports/impact-rapm/rapm.csv` 的 pooled*；分半用 `reports/ovr-v58-holdout-2025-26/rapm-{A,B}.csv`）。等權合併會把三、四年前的表現和上一季同等看待：年輕且在進步的球員會被舊季拖低，正在退化的老將則會被舊季撐高。

H：把 RAPM 改成近期加權（季權重 d^(距離最近一季的季數)，0 ≤ d < 1），預測下一季的表現會比等權合併（d = 1）更準；而且卡片換用它之後，在每場影響力的樣本外量尺上不會變差。

## 2. 第一階段：RAPM 層的前瞻檢驗（主判定 P）

### 2.1 資料

- stint：`reports/impact-rapm/rapm.py` 的 `observations()` 與 `stint_path()`。有的季：2014-15..2020-21、2022-23..2025-26（沒有 2021-22）。
- 如果 2014-15..2020-21 的 stint 用 `observations()` 讀不了，或欄位意義不同，就停下回報，不自行轉換。

### 2.2 近期加權 RAPM

- 模型、設計矩陣、符號都和 `rapm.py` 的 `normal_equations`／`solve` 相同（得分 = 截距 + Σ進攻 O − Σ防守 D，權重是回合數）。
- 唯一改動：窗口中第 s 季的每筆 stint，權重乘上 w_s = d^(T − s)。T 是窗口中最近的一季，以季數計，而且跳過 2021-22 不算一季。
- λ 固定 3000，所有 d、所有窗口都一樣，不重選。
- 實作建議（不影響結果）：XᵀWX、XᵀWy 對權重是線性的，可以每季各累加一次再加權相加。
- 衰減率格點：d ∈ {1.0, 0.75, 0.5, 0.25, 0.0}。d = 1 就是現行等權合併；d = 0 是只用最近一季（0⁰ = 1）。

### 2.3 指標

- 用窗口擬合出 O、D，預測目標季每筆 stint 的 y = 100·pts/poss：ŷ = c_t + ΣO − ΣD。
- **截距 c_t 一律用目標季自己的回合加權平均 y**，所有候選相同。這樣聯盟得分水準逐年變動的影響不會算到近期加權頭上。
- 窗口裡沒有係數的球員（新秀等）O = D = 0。
- 指標是目標季的回合加權 MSE。

### 2.4 選 d（只用舊季）

- 選擇目標季：2017-18、2018-19、2019-20、2020-21，各用前三季當窗口（例如 2017-18 用 2014-15..2016-17）。
- 4 季 MSE 的平均最小的 d 就是 d*。平均差 < 1e-6 視為同分，取較大的 d（較接近現行）。
- d* = 1：整個實驗結束，記為「等權合併已是最佳」，不做第二階段。

### 2.5 檢驗（一次）

- 主檢驗：窗口 2022-23..2024-25 → 目標 2025-26。
- Δ = MSE(d*) − MSE(d = 1)。bootstrap 以目標季的比賽（gameId）為單位重抽 2000 次，seed 20261029，兩個候選共用抽樣。
- **(P) 過：Δ 的 90% 區間上界 < 0。**
- 只報告：窗口 2022-23..2023-24 → 目標 2024-25 的同一指標。
