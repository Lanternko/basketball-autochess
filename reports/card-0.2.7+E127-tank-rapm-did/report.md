# 總評
**4/5 大致達成 有部分退步**

**這次目標**
比較 S 季 RAPM 和年齡都相同的兩個年輕人，看 S 季在爛隊的那一位，隔年 RAPM 會不會補漲，藉此判斷 β8 的折扣扣到的是「人」還是「環境」。（預註冊加上已核可的 errata-1。）

**進步了什麼**
- 問題有了明確答案：判定是**「折扣是真的」**。
  - 爛隊年輕人隔年的補漲，不到 card 0.2.7 對他們扣分的一成。點估計是 −3%，上界 25%，判定門檻是 50%。
  - β8 大致合理，card 0.2.7 和 R-035 保留。
- 表面上的補漲其實是均值回歸：
  - 原始數字看，爛隊年輕人隔年 RAPM 平均比其他年輕人多漲 +0.79。
  - 控制「去年本來就低」之後，差距變成 −0.04。
  - 也就是說，去年數字低的人隔年都會回升，和在不在爛隊無關。
- 用另一種 L 算法（只算有 DNP 資料的場次）重算，判定相同。舊季缺場不影響結論。

**退步了什麼**
- 使用者主張的情境有一部分訊號，但樣本太小：
  - 「換隊」子組隔年多漲 +0.69，區間不含 0，但只有 9 人次。
  - 「隔年球隊變好」子組 +0.40，區間跨 0。
  - 這兩組都只是報告項，不能當證據。另外，Flagg 是隊友換了，他自己沒換隊，嚴格說不屬於「換隊」這組。
- 爛隊老將隔年反而更差（−0.46，區間不含 0），代表爛隊的資料本身有選擇效應（留下來的老將在走下坡）。這點沒有在預註冊裡事先想到。
- 爛隊年輕人隔年流失的比例比較高（25%，好隊年輕人是 9%），可能有倖存者偏差。不過被淘汰的人多半是去年表現差的，而他們沒算進來，所以實際補漲可能比估計的還小。
- 第一次跑在 phase 0 卡關（門檻範圍寫太寬），多花了一輪 errata。
