# 第三步提案：跨季純球員卡測試（本步不執行）

主線只用個人 box、個人投籃分區／防守對位追蹤、身材與公開角色資訊；五組區段訊號關閉，不把球隊淨勝分、球員在場攻守值或殘差寫回卡。v1–v5 保持凍結，新的跨季輸入與全局常數另存並記 SHA-256。

## 三組跨季

2022–23→2023–24、2023–24→2024–25、2024–25→2025–26。能力與聯盟常數只由 N 季截至結束的資料估計，不使用 N+1 的球員表現。現有三個切點卡只到 N 季 25／41／55 附近，不能冒稱整季卡；完整 N 季個人防守追蹤等若不在快取，需要下一步補抓。四個球季已看過答案，這些跨季測試都只能標「開發季診斷」，不能稱盲測。

## 新秀與缺資料

有 N 季 NBA 樣本者沿用固定 v3 個人建卡與收縮規則；低樣本卡如實標明曝光與缺漏。新秀／完全沒有 NBA 樣本者用 N 季新秀個人數據的身高位置組先驗，不用球隊效應：觀測身材直接保留，出手、失誤、助攻、籃板與命中依組內個人觀測估計；位置組不足30人按 n/(n+30) 向全體新秀先驗回縮。無法識別角色時只用位置，不虛構控球／掩護觀測。若 N 季無完整新秀辨識資料，退回可辨識的新加入球員先驗並列失敗；不得用 N+1 成績補值。先驗規則與常數在任何測試輸出之前再正式登記，這裡是提案，沒有建卡。

## 分鐘與名單兩版

1. 條件式上限版：N 季卡，N+1 真實逐場可用名單／先發與真實分鐘；未來資訊只用在這個明確標示的診斷曝光，不進能力。它回答卡在曝光完全已知時能否描述重新組隊。不能當季前預測，也不能與事前版混表。另列用 N 季平均分鐘加已知可用名單的中間版，隔離真實分鐘的比分結果洩漏。
2. 真正事前版：只用 N+1 開季前公開名單與已知傷停。轉隊球員帶著 N 季卡；分鐘以 N 季 MPG、角色、位置覆蓋與公開輪替假設決定，正規化240、單人上限48。新秀分鐘依已登記角色先驗，所有人工角色／傷停假設留來源與快照。未知的未來交易、傷停與教練變更不補入。出勤情境由 N 季個人出勤與聯盟缺陣模型估計，規則只在開發資料中定一次，季前封存後不回填。

## 對照與評分

- 對照一：N 季真實淨勝分原樣沿用；對照二：N 季淨勝分回歸聯盟平均。收縮只由 N 季資料決定，採預先登記的 league empirical-Bayes reliability：max(0, between-team variance − estimated within-team sampling variance)／between-team variance，限制0–1；與直接沿用者並列，不按球隊重估。這兩項只當對照，不寫進純卡輸出。
- 淨勝分：每季30隊去均值與原始 RMSE／MAE；排序 Spearman、Pearson與校準斜率；戰績：82場 expected wins MAE／RMSE。三季等權合併，20個同 seed；franchise 與 seed 跨季共用重抽，20000次聯合95%區間。三個已看過的季配對不能被當作三個新盲測。
- 陣容延續比例：把 N 季球員分鐘占比與開季預估分鐘占比都正規化為1；C=Σ同一球員 min(wN,wNext)。分 C<.5、.5≤C<.75、C≥.75。分組只用當時可知的名單與預估分鐘，先固定再評；各組報球隊數與三項指標，少於10個球隊季樣本標記不足。真實後段分鐘算出的 C 只列答案側敏感度。
- 主要檢查：純卡相對較強簡單對照是否提供跨季／低延續陣容增益；同時拆 oracle 分鐘與真正事前分鐘之間的落差。不要把名單已知版勝過對照說成季前成功。
