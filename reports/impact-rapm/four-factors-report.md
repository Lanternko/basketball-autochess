# 四因素 RAPM：防守價值從哪裡來（2022-23～2025-26）

**結論：每一項防守因素都是可重現的個人能力。** 外線防守專家的價值，大約一半來自「讓對手少出手」，一半來自「讓對手命中率下降」，這和使用者描述的機制一致。模擬目前抄截做得很準，但**抄截以外的失誤完全沒有**，命中率的壓制也被壓縮了。

資料：262,169 筆 stint、877 位球員。結果檔：`four-factors.csv`、`four-factors-summary.json`。

自我測試中，沒有個人效果的因素可靠度是 −0.16，所以這些數字代表真實的個人差異。

**但「可重現」不完全等於「個人能力」。** 球員兩半的隊友和教練戰術大多相同，RAPM 雖然控制了同場球員，仍可能有一部分是團隊體系被算到個人頭上。

## 對照使用者描述的機制

- **讓對手少出手（傳球、重來、失誤）**：Caruso、Smart、Herbert Jones 的價值，有很大一部分在出手量，而且不只來自抄截，也來自抄截以外的失誤。
- **硬要出手時效率下降**：每一類好防守者都有這一項；內線護框者（Wembanyama、Gobert）主要靠這個，外加嚇阻對手不敢攻擊籃下。
- **弱防守者**：Brunson、Trae、Curry 的代價主要在命中率和罰球，不在出手量。
- **撲防不及、對手有空檔時干擾變小**：stint 資料沒有助攻標記，這次無法檢驗。

## 和模擬的差距

| 管道 | 模擬現況 |
|---|---|
| 抄截 | 已用實測抄截率建模，重現準確（例如 Caruso 真實 2.54、模擬 2.37 次／36 分鐘） |
| 抄截以外的失誤 | **沒有防守者相關的機制**，只看進攻持球者自己的控失誤能力 |
| 命中率壓制 | 有實測的五區防守係數，但被強烈收縮。在場對手命中率的標準差：模擬 1.22、真實 1.75 |
| 出手位置（嚇阻） | 有實測的出手選擇係數，是否被壓縮尚未檢查 |
