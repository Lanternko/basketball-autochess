## 重跑及完整輸出

`npm run season:build` 離線從44份官方快照重建；`npm run test:season` 驗證賽程、來源與核心記帳；`npm run simulate:season -- --seed 20261012` 重跑。

- 完整賽季：[JSON](nba-season-2025-26-seed20261012.json)。包含30隊、全部球員、1230場結果與來源／程式雜湊。
- 逐場球員box score：[JSONL](nba-season-2025-26-seed20261012-games.jsonl)。每行一場。
- 一個seed只有一季，尚無重複球季區間；真實比分和戰績僅用於本報告比較，不進入引擎決策。
