# 替補可靠度收縮：執行結果與結論（2026-10-18）

## 結論：不採用

依 `preregistration.md` 預先登記的四組關卡，**G1（不劣化）與 G2（主要改善）未通過**，G3、G4a/b/c 通過。
依照預註冊規則「全部關卡都要過才採用」，本次**不把輸出層可靠度收縮接到正式卡片板**。
正式卡片板維持 Part 1 的混合版（α = 0.5，`reports/ovr-calibrated-2025-26/`）現狀，不做任何改動。

κ 以方法動差法（method-of-moments，`m_i` 加權）估計，但因 σ² < 0（分母項落在不合理區間），
觸發預註冊的備援規則，**改用固定 fallback κ = 500**（非從關卡指標中挑選，詳見下方「κ 的來源」）。
κ 網格（250 / 500 / 1000 / 2000）**只做透明度檢查，不影響本次決策**——四個網格值全部都不能同時通過
G1 與 G2，顯示不採用的結論並非 fallback κ 造成的偶然結果，而是在整個預註冊允許的 κ 範圍內都成立。

## κ 的來源

- 方法：對 `m_i ≥ 50`（card-minutes）的球員，用權重 = m_i 的加權最小平方法，迴歸
  `(p_i − μ_pos)² ~ 1 + 1/m_i`，解出 τ²（截距）與 σ²（斜率），κ = σ² / τ²。
- 實測：`τ² = 1.7727`，`σ² = −35.6518`（535 名球員參與估計）。
- σ² 為負，不滿足模型假設（殘差變異應隨 1/m_i 遞減），依預註冊備援規則：**κ 改用固定值 500**，
  並標記 `kappaSource = "fallback"`、`kappaClippedToBound = true`。
- 另外用獨立腳本驗證：不論加權或不加權最小平方法，σ² 都是負值（加權 −35.65、不加權 −39.25），
  且按分鐘分組的殘差平方均值並非隨分鐘數單調遞減（500–1000 分鐘組平均 2.10，高於 1000–2000 分鐘組
  的 1.46，而 ≥2000 分鐘組反而最高，達 2.09）。這確認了 σ² < 0 是這份資料本身的性質，
  不是程式錯誤——正是預註冊備援規則設計要攔截的情況。

**重要：κ 並非依任何關卡指標挑選。** 下方的 κ 網格表（250/500/1000/2000）純屬透明度檢查，
用來確認「如果採用別的 κ，結論會不會不同」，而不是從中挑一個讓關卡通過的值。

## 已知限制（沿用自預註冊文件，執行後重新確認仍成立）

1. **OVR 不再是純屬性函數**：收縮後的 OVR 取決於 `m_i`（卡片分鐘），兩張屬性完全相同但卡片分鐘
   不同的卡，會得到不同 OVR。這與目前卡片 OVR「由屬性決定」的既有心智模型不相容。
2. **尺標錨點不可跨版本比較**（已在上方驗證：PR1/PR50 改變、PR99 不變）。
3. **sim R² 下降（0.4154 → 0.3216）未設下限門檻**：本次執行只呈報、不攔截,預註冊本身也未對此
   設置獨立關卡，但下降幅度不小,值得注意。
4. **RAPM 循環性**：收縮目標的位置均值 μ_pos 來自同一批已經混入 RAPM 的校準目標（α=0.5），
   與 G1/G2 關卡評估用的 RAPM 淨值/防守 ρ 並非完全獨立的資料來源，只是訓練/留出折做了基本切分。
5. **風險 #1 已驗證成立**（見上方 81 人清單）：極低分鐘球員的 OVR 會被先驗拉高,而非只壓低
   高名次的小樣本球員。

## 本次執行與κ的獨立性聲明

κ 的最終值（fallback 500）僅由方法動差法估計失敗後的預註冊備援規則決定，**沒有依任何關卡
指標（G1–G4）回頭調整或挑選**。κ 網格表（250/500/1000/2000）為預註冊明訂的「透明度檢查」，
同樣只用於確認結論穩健性，不作為選擇依據——四個值皆不採用,與 fallback 值的結論一致。
