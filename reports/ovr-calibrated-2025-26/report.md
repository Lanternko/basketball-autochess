# 模擬校準的能力值 OVR（2025–26，4 組種子版）

**結論：公式已經可用，約 1 秒完成校準，之後套公式即時算出 OVR。** 它抓到了模擬結果中約四分之三的可解釋差異。但它也照單全收了模擬本身的盲點：中距離和持球防守在模擬裡幾乎不值分，所以 Brunson、Cade 仍然偏低。

`python3 reports/ovr-calibrated-2025-26/calibrate.py`，輸出 `ranking.csv` 與 `summary.json`。本機的 24 組種子跑完後，執行：

```
python3 reports/ovr-calibrated-2025-26/calibrate.py --target reports/ovr-v47-2025-26/resample-ranking.csv
```

## 做法

- **目標**：v47 模擬貢獻值，經過第 1 步的位置校正，換算成每 36 分鐘。
- **輸入**：卡片能力值（40～99 的百分位刻度）加上身高，共 13 項。
- **擬合**：加權迴歸。權重是「1 ÷（抽樣變異 ＋ 殘差變異）」，所以抽樣雜訊大的替補球員比重較低。
- **選模型**：只看重複 5 折交叉驗證，從「線性」和「依位置調整五項能力的斜率」兩種形式、以及六種正則化強度中挑選。
- **顯示分數**：PR1 對應 40、PR50 對應 70、PR99 對應 99（至少 500 分鐘的球員）。

## 模擬本身的盲點，公式會繼承

1. **中距離和持球防守幾乎不值分。** 所以中距離型的 Brunson 排第 337、Cade 第 116。這是模擬給出的評價；要改善，得先改模擬，不能只調公式。
2. **實際球員的模擬，不完全由能力值驅動。** 實際球員在模擬中，投籃、防守和罰球部分用的是實測數據（shootingMeasurement、fineDefenseMeasurement 等），所以公式學到的是「能力值和實測數據的相關」。用在虛構卡片上時，模擬是走能力值的路徑，兩者未必一致。上線給虛構卡片用之前，應該用一批虛構卡片實際模擬驗證。
3. **無球、掩護、運球、破包夾全員都是 70**，所以無法被估價。
4. **身高是負係數，但信賴區間很寬。** 很可能是和體格、籃板等能力重疊造成的，不要當成「越高越差」解讀。
