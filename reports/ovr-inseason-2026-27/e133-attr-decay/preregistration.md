## 0. 設計：四條原則怎麼對到公式

現行 C4 對能力值 a 的預測是：

  x = f·y + (1−f)·(x0 + b·(y − x0))，b = n / (n + k_eff)，k_eff = σ²_a / (δ²_a + σ²_a / n舊)

- σ²_a 是單一樣本的雜訊，來自 `fit/reliability.csv` 的分半信度。
- δ²_a 是真實能力一季之間的變化量，用更早起點的「先驗卡對答案卡」配對估出（`delta2_from_pairs`）。
- f＝N/G 是定義，這次不動。這次只改「用已打的場次預測剩下比賽」那一段，也就是 b 和 y 的加權。

| 原則 | 現行 | 本實驗 |
|---|---|---|
| 2 換季大降 | δ²_a 全體共用一個值 | **δ²_a 分年齡**：目標季開季 ≤ 23 歲、≥ 24 歲各估一個，估法照 `delta2_from_pairs`，只把配對限在該年齡組。沒有自由參數 |
| 3 分項目 | σ²_a、δ²_a 已經分項目 | 保留；季內遺忘率也分項目（下一列） |
| 1 每場遺忘 | 本季每場一樣重 | 本季第 j 場（j=0 是最近一場）權重 w_j = max(0, 1 − s_a·j)。用 n_eff = Σ w_j·n_j 和加權平均 y_w 取代 n、y，**只用在 b 那一段**；f·y 那一段仍用不加權的 y，因為季末卡是整季平均 |
| 3 不穩定的慢 | — | s_a = s0 · u_a，u_a = (δ²_a / σ²_a) ÷ 各項目 (δ²/σ²) 的中位數。雜訊大、真實變化小的項目，u_a 小，遺忘得慢 |
| 4 直線 | — | 判定只用直線；指數曲線只報告（§2.5） |

### 2.3 選 W*（只用訓練起點）
- J = 訓練起點 × N ∈ {3, 5, 10, 20} 的 MAE 等權平均。
- 5 個候選取 J 最小的一個。J 差 < 0.005 算平手，依序選 B0 → M1 → M2-a → M2-b → M2-c，越保守越優先。
- W* 是 B0 時判「沒有改善」，不跑測試。

### 2.4 測試與判定（只此一次，不重試，L-026）
在 D1、D2、D3 只跑 W* 和 B0。dMAE = MAE(W*) − MAE(B0)，以球員為單位做配對 bootstrap，2000 次，seed 1。

| 結果 | 條件 |
|---|---|
| **採用候選** | ① 3 起點 × N=10、20 共六格合併 dMAE 的 90% 上界 < 0；② 這六格各自 ≤ +0.05；③ N=3、5 的六格各自 ≤ +0.05；④ W* 對 A 仍過 v5 V1∧V2 |
| **沒有改善** | 只有 ① 不成立 |
| **候選較差** | ②、③、④ 任一不成立 |

- 「採用候選」要交 role-audit 重算和使用者 G5，通過後版號 inseason PATCH。
- 不論判定如何，都不改卡片。

### 2.5 只報告
