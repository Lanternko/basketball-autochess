## 1. 為什麼要改（看過 v4、v5 D1–D3 結果，已揭露）

1. **C3 的權重不看球員上場量。** `fit_w_grid_v4.py` 的 `c1_predict` 用 `wgrid[a][N]`，同一項能力值、同一個 N，所有球員共用一個 w。一個打 30 分鐘的先發和一個打 5 分鐘的替補，在 N=10 時更新幅度一樣。這違反「樣本少就該更靠近先驗」的基本要求，也是少場次球員不可信的直接原因。
2. **λ(N) 每個 N 各挑一個，曲線沒有單調性保證。** v4 的 D2：N=5 跟 A 平手（+0.006），N=10 輸 0.34，N=20 又贏。準確度在 N=10 往下掉沒有道理，這是 E 太小時逐 N 挑參數的雜訊。
3. **季末接不上季末卡。** C3 在 N=82 時 w·λ 一般小於 1，整季打完還在往先驗拉，跟「最後平滑銜接季末分數」的目標矛盾。
4. **原則上應該做到「不輸 A」。** 用校準過的收縮，從先驗出發、加上新資料，期望誤差不該比先驗大。v4 輸掉的四格裡有三格是 +0.005、+0.006、+0.12 的平手，唯一實質輸的是第 2 點的 N=10。

分岔路揭露：C4 是看過 v4 結果和 v5 D1–D3 結果後才提出的。D1–D3 本來就是「已看過、只當次要」（v5 §0.1），所以 C4 在 D1–D3 的數字一律不得當作證據；**唯一的證據是 Path A 的 Y3/Y5/Y6，目前一個數字都還沒產出**。

## 2. C4 的公式（寫死）

對起點 s、場次 N、球員 i、可更新能力值 a：

```
n_i      = IC.sample_of(rec_i, a)                  # 球員本人前 N 場的樣本量（與 C2 相同）
k_i,a    = c · k_eff(δ²_a, σ²_a, n^p_i,a, nRef_a)  # v2_common.k_eff，δ² 由 E(s) 估，c 見 §3
b_i,a    = n_i / (n_i + k_i,a)                     # 剩餘賽季的收縮權重
f_s(N)   = min(N / G_s, 1)                         # 已打賽季比例；G_s = 該季每隊例行賽場數
w_i,a    = f_s(N) + (1 − f_s(N)) · b_i,a
x̂_i,a    = clip( x0_i,a + w_i,a · (y_adj,i,a − x0_i,a), 40, 99 )
```

- **f 的來由**：季末卡是整季的平均。整季 = 已打的部分（權重 f，已觀測）＋剩下的部分（權重 1−f，未觀測，用收縮估計 x0 + b·(y−x0) 預測）。兩段合起來就是上式，不是另外加的自由度。
- **G_s**：一般季 82；2019-20 用各隊實際例行賽場數（泡泡季，Y4 本來就是暖身）；2020-21 用 72。
- **低於 `SEASON_MIN_SAMPLE[a]`**：x̂ = x0，與 v4 相同。先驗卡沒有該球員時，同樣是 x̂ = x0（人群定義不收新人，見 §4）。
- **凍結項**（physique、heightInches、onBall、help 與 v5 現行凍結清單）：w=0，與 v4 相同。
- **y_adj**：照 v4/v5 管線（含 U2 拿球調整、E2-λ0.4），不改。

### 2.1 這條式子自動保證的性質（不用回測去碰）

| 性質 | 為什麼成立 |
|---|---|
| N=0 時等於 A | f=0、n=0 → w=0 |
| 少上場的人更新少 | n_i 小 → b 小 → w 接近 f |
| 隨場次單調 | f 隨 N 遞增，n_i 隨 N 不減，b 隨 n 遞增，所以 w 隨 N 不減（對每個球員） |
| N=82 時可更新項等於整季觀測 | f=1 → w=1 → x̂ = y_adj(82) |
| 沒有逐 N 的參數 | 全部 N 共用同一個 c；不會再出現 N=10 單獨塌陷 |

**N=82 銜接的限制（照實寫）**：只有可更新項會落在整季觀測上。凍結項整季都停在 x0，而季末卡的凍結項來自整季資料與 RAPM，所以 N=82 的 OVR 一般不會完全等於季末卡。上線時在季末直接換成季末卡（看得到的跳動就是凍結項的差）；報告要把 N=82 殘差拆成「可更新項」與「凍結項」兩塊（§5.2）。

## 3. 唯一的自由度 c（取代 λ(N)）

- **意義**：k_eff 的全域倍率。c>1 代表比貝氏公式更保守（更靠近 A），c<1 代表更積極。它處理「σ² 低估、各項誤差同向疊加」這類整體偏差（v4 §1 的 C1 失敗原因）。
- **格點**：c ∈ {0.25, 0.35, 0.5, 0.7, 1, 1.4, 2, 2.8, 4}（對數等距，9 點）。
- **目標函數**：`J_s(c) = (1/4) · Σ_{N∈{3,5,10,20}} J_s,N(c)`，其中 J_s,N 照 v5 §3.1（N=3/5 用中位數、N=10/20 用 MAE，E_eff 內起點等權）。**一個 c 套用全部 N**。
- **E 集合**：完全照 v5 §3.2 的 E 與 E_eff 表，判定門檻 |E|≥3、|E_eff|≥2 不變。
- **δ²_a**：照 C2 的 `drift` 估法，只用 E(s) 內的起點（嚴格更早）。
- **平手**：J 差 ≤1e-9 取較大的 c（較保守、較靠近 A）。
- **c 恆大於 0**，所以 §2.1 的單調性對任何被選中的 c 都成立。
- **穩定度診斷**（只報告，照 v5 §3.3 的寫法）：高原寬度（J 在最小值 +1% 以內的 c 區間，以 log₂ 計）、留一起點的 c 變化。

## 5. 新增的報告項目（只報告，不當閘門）

### 5.1 單調性

每個新鮮主判定起點畫 MAE(N)，N=3/5/10/20/82，A、C3、C4 三條線。C4 若在任何相鄰兩個 N 之間 MAE 上升超過 0.10 分，報告標「非單調」，寫出是哪幾個球員造成的，但不改判定。

### 5.2 N=82 拆解

N=82 時，C4 對季末卡的 OVR 誤差拆成兩塊：只換可更新項的 OVR 差、只換凍結項的 OVR 差。用來說清楚「季末銜接」差在哪裡。

### 5.3 依上場量分組

P_s(N) 照視窗內場均分鐘切三組（<15、15–28、≥28），分別列 A 與 C4 的 MAE。這是直接回答「少場次的人可不可信」。

### 5.4 沒有先驗卡的球員（新人、前季 MIN<500）

目前人群定義不收這群人，C4 也不處理他們。本 errata **只列為待辦，不在 v5 解決**：
- 需要另外的起點先驗（例如位置 × 選秀順位 × 分鐘級距的中位數卡），以及獨立的驗收人群。
- 上線時這群人要在卡片上標「樣本不足」，不顯示假精度。
