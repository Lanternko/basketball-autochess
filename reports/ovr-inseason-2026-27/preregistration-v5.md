1. N=3/5 的中位數差 CI 很寬（約 0.7–1.1），點估計卻接近 0；用「CI 上界 ≤ 0」當判準會幾乎全部失敗，統計檢定力不足。所以 N=3/5 只能做非劣性檢定（容忍值），不能要求嚴格小於 A。
2. N=10/20 的 MAE 差在舊答案上全部為負；但 CI 上界只有 D2-N20（−0.2934）、D3-N10（−0.2823）、D3-N20（−0.6511）小於 0，D2-N10 是 +0.1373。MAE 比中位數穩定，但 n≈260 的檢定力仍有限。
3. D2-N10 是關鍵：中位數差 +0.34（變差），MAE 差 −0.21（變好）。**同一組預測，換統計量就換結論**；這是 §8 必須揭露的分岔。

### 1.4 指標分歧

| 格 | 中位數 | MAE | 結論方向 |
|---|---|---|---|
| D2-N10 | +0.3425（C3 較差） | −0.2106（C3 較好） | 相反 |
| D3-N3 | +0.1157（C3 較差） | −0.1397（C3 較好） | 相反 |
| D3-N5 | −0.0550（C3 較好） | −0.5123（C3 較好） | 相同 |
| D2-N5 | +0.0059（C3 較差） | −0.1680（C3 較好） | 相反 |

中位數只看排序中間那一點，MAE 看整體誤差量；C3 在 N=10/20 把極端誤差拉回來，但中間那個人可能退步。v5 的處理不是「選一個好看的」，而是**每個 N 用哪個統計量，事先寫死**：N=3/5 用中位數（少量場次、極端值不可信），N=10/20 用 MAE（使用者指定）。

## 2. 驗收標準（使用者定案）

### 2.1 共同定義

對每個起點 s、每個 N∈{3,5,10,20,82}：

- **P_s(N)**：v4 §5.2 的人群，完全不改。前一季 MIN≥500、目標季全季 MIN≥500、視窗前 N 場 MIN≥1；新人不列入；被交易球員照答案卡跨隊加總。
- **視窗**：目標季該隊前 N 場。N=82 是整季，只報告，不判定。
- **A**：先驗卡 x0，整個視窗固定不變。
- **C3**：`x0 + λ_s(N) · w_s(N) · (y_adj − x0)`（`fit_w_grid_v4.py:168` 的同一條式子）。λ=0 時 C3≡A；λ=1 時是 C1。
- **y_adj**：賽中觀測 OVR 代理，照 v4 管線。
- **e_A,i、e_C,i**：球員 i 的預測 OVR 減答案卡 OVR；正數代表高估。
- **中位數差**：T_s = median(e_C) − median(e_A)。
- **MAE 差**：dMAE_s = mean(|e_C|) − mean(|e_A|)。
- **>10 人數**：|e|>10 的球員數，A 與 C3 各一。
- **母體下限**：P_s(N)<200 的起點不得判定，自動降為暖身，並在報告列出。258–284 是 v4 的實際範圍，200 只是安全地板，不是目標。

### 2.2 N=3/5：不輸就好（非劣性）

對每個新鮮主判定起點 s：

1. 在 P_s(N) 內重抽玩家（有放回，n 不變），B=2000，seed=20261027，同一隨機順序（起點照鏈順序、N 由小到大）。百分位用線性插值，與 `bootstrap_v4.py` 相同。
2. 每個重抽樣本算 T_s^b = median(e_C^b) − median(e_A^b)。
3. 取 95% 雙尾區間的上界 U_s = 第 97.5 百分位（比單尾 95% 的第 95 百分位保守；與 `bootstrap_v4.py` 的診斷一致）。
4. 單一起點護欄：T_s ≤ **+0.25**。
5. 新鮮主判定起點等權平均：T̄^b = (1/|H_fresh|)·Σ_s T_s^b；U_pool = 第 97.5 百分位。
6. **通過條件**：U_pool ≤ **τ=0.50**，且每一個新鮮起點都 T_s ≤ +0.25。

- 等權平均是「每個起點一票」，不讓球員多的起點獨大；這和 §3 的 λ 目標函數一致。
- 只 pooled 當閘門、單一起點只看點估計，是為了避免多重比較把檢定力吃光；護欄 +0.25 防止「一個起點爛很多、被其他起點平均掉」。
- |H_fresh|=1 時 pooled 就是該起點；|H_fresh|=0 時主判定從缺（§2.6）。
- 每個起點的 U_s 仍然要報告，但不當閘門。

**容忍值 τ=0.50 的理由（事先寫，不能看結果改）**：

- 尺度：v4 的中位數誤差是 4.46–5.89 分，MAE 是 5.80–7.37 分；0.50 分約是中位數誤差的 8–11%、MAE 的 7–9%。
- 顯示精度：正式卡 `ranking.csv` 四捨五入到小數一位（`calibrate-wing.py:419`），0.50 分是顯示單位 0.1 的五倍，但仍是「半個大格」；比它小的差異在卡片上看不出來。
- v4 的 P3 卡片驗收用 |中位數差|≤1.0（v4 §6）；0.50 是它的一半，方向一致（賽中預測比季末卡片難，容忍值不該比 P3 更寬）。
- 舊答案的 null 上界：N=3/5 四格的 U_s 是 0.2587、0.4086、0.4603、0.2705；τ=0.50 可以覆蓋全部。這代表「真差不為負」時不會因為抽樣噪音被誤判失敗；代價是「真的退步 0.5 分」也可能過。這個取捨寫在 §8，不藏。
- τ 的敏感度（舊答案、只做診斷）：0.25 → 0/4 格通過；0.40 → 2/4；0.45 → 3/4；0.50 → 4/4；0.75 → 4/4。**0.50 是以 0.05 為級距、第一個讓四格全過的門檻**，這一點在 §8 明確揭露。

**點估計替代方案（敏感度，不當主判定）**：所有新鮮起點 T_s ≤ **+0.10**，不跑 bootstrap。舊答案下 D2-N3（+0.005）、D2-N5（+0.006）、D3-N5（−0.055）過，D3-N3（+0.116）不過；這條比 τ=0.50 嚴，沒有為了讓 v4 過而放寬。列為 Q2。

### 2.3 N=10/20：MAE 嚴格小於 A

對每個新鮮主判定起點 s：

1. dMAE_s = MAE_C − MAE_A **< 0**（嚴格，沒有容忍值）。
2. >10 人數：count_C,s ≤ count_A,s。
3. 兩個條件都成立才算該起點過。
4. 所有新鮮起點都過，N=10/20 才算過；不用 pooled 代替個別起點（個別都 <0 時 pooled 必然 <0，pooled 只報告）。
5. bootstrap 的 MAE 差 95% CI 要報告，但**不當閘門**（Q3）。CI 上界 <0 標「強」，上界 ≥0 但點估計 <0 標「方向一致」，兩者都算過。
6. 材料性：|dMAE_s|≥0.10 另外標記；<0.10 的過關在報告寫「統計上過、實務上小」。

- 為什麼 N=10/20 不用中位數：使用者指定 MAE 當主指標；且 §1.4 顯示中位數在 N=10 會和 MAE 反向。
- 為什麼保留 >10：MAE 是平均，少數球員爆掉會被平均掉；>10 人數是尾部護欄，使用者的原始 spec 也建議保留。
- 為什麼不需要「嚴格小於」的容忍值：嚴格小於本身就是最嚴的點估計規則；再加 bootstrap 會把檢定力問題帶進來（Q3）。

## 3. λ 的目標函數與判準對齊

### 3.1 目標函數（寫死）

對起點 s、場次 N，λ 在 E(s) 上挑：

- N=10、20：`J_s,N(λ) = (1/|E_eff|) · Σ_{h∈E_eff} MAE_h(λ)`。
- N=3、5：`J_s,N(λ) = (1/|E_eff|) · Σ_{h∈E_eff} median_h(λ)`。
- N=82：`J` 用 MAE，只報告，不拿來預測（λ_82 = λ_20）。
- `MAE_h(λ)`、`median_h(λ)` 是在 h 的 P_h(N) 上算 C3 對答案卡的誤差；C3 用 h 自己的 x0、w_h(N)、y_adj。
- **每個起點等權**，不是把所有球員混在一起算。理由是 §2 的閘門也是起點等權；若 λ 用球員混池，球員多的起點會主導 λ，閘門卻給它一票，兩邊不一致。
- λ 格點 {0, 0.05, …, 1.00}；平手（差 ≤1e-9）取較小的 λ；**不強制單調**。v4 的 D3 非單調是 E 太小的症狀，v5 用「E 至少 3 個起點」處理，不是事後套單調。
- 敏感度：另外算「球員混池」的 λ、以及「中位數λ／MAE λ」互換的 λ，只報告，不改變主選擇。

### 3.2 E 集合與「至少 3 個更早起點」

- **E(s)**：比 s 早、有答案卡、RAPM 季集和 v5 規則一致的所有起點。**W 不進 E**：W 是 RAPM-free、OVR 尺度和正式卡不同，v4 也沒有把 W 放進 D1 的 E（`v4/fit/lambda.json` 的 D1 E 為空、λ=1）。W 只當 D1 的前一個起點，不參與 λ 選擇。
- **E_eff(s)**：E(s) 中，自己的 w 不是退化（至少有一個更早起點可以 fit w）的起點。Y0 的 w 退化（H=∅），所以 Y0 不進 E_eff；Y1 的 w 可以從 Y0 fit，所以 Y1 進 E_eff。
- **判定門檻**：`|E(s)| ≥ 3` 且 `|E_eff(s)| ≥ 2`。兩個都滿足才算「λ 有足夠資訊」，否則該起點只能暖身。
- Y0 進 E 但不在 E_eff：它對所有 λ 的預測都等於 A（w=0），J 是常數，不影響 argmin；保留它只是讓「起點數」的計數和鏈一致。這句話是事先寫的，不是看結果補的。

### 3.3 λ 穩定度診斷（只報告）

1. **高原寬度**：J 在最小值 +1% 以內的 λ 區間長度。
2. **留一起點**：E_eff 每次去掉一個起點重挑 λ，看 λ 變化。
3. **兩目標互換**：中位數 λ 與 MAE λ 的差。
4. 判定：高原寬度 >0.30 或留一變化 >0.30，標「不穩定」；**不改變主選擇**，只影響報告的置信度描述。

### 5.1 D0：資料閘門（先過這一關）

D0 的驗收不是「程式跑完」，是**每一季每一層都有檔案、且場數正確**：

|---|---|---|
