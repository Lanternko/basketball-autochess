## 2. 指標定義

- `中位`＝|誤差| 的中位數；`MAE`＝|誤差| 平均；`>10`＝|誤差|>10 的人數。
- `T`＝median(e_C3) − median(e_A)，e = 預測 OVR − 答案 OVR；方括號是玩家重抽 bootstrap 95% 區間（B=2000、seed=20261027、numpy linear 百分位）。負值＝C3 的中位誤差較小。
- 舊答案（v4）N=3/5/10/20 讀 `v4/backtest/results.csv`；N=82 由 `legacy_n82_v5.py` 用**未覆寫的 v4 模組**重算，且該程式重算 N=20 與 v4 結果的最大差為 0.0，確認流程一致。
