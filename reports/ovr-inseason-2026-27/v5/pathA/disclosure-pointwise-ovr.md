# 揭露：賽中 OVR 改逐點計算（Path A 判定前）

- 日期：2026-10-28
- 依據：使用者 2026-10-28 回覆：「能力值沒變就不要變吧，不用遷就 2K。OVR 是絕對數字，可以跨季比較。沒變就是一樣強，只是不同賽季的 86.57 可能名次不一樣。」
- 時點：errata-c4 §6 第 1 步（等價檢定）之後、第 3 步（選 c、跑閘門）之前。**寫這份時還沒有任何 Path A 的 A／C3／C4 判定數字。**
- errata-c4 本身不改（它寫明凍結後只能另寫揭露）。

## 1. 發生什麼事

等價檢定 T1（f=0、k 取 `k_eff` 上界，C4 應幾乎等於 A）用原凍結管線算 OVR，三格超過 0.5 分：Y3 N=3 0.541、Y3 N=5 0.543、Y4 N=5 0.604。
原因不在 C4：能力值最大只動 0.47，但 v58 管線有兩處依「當下這群人的名次」計算：

| 部分 | 原算法 | 問題 |
|---|---|---|
| H1 封頂 T(A) | 當下第 A 高的 pred，固定點迭代 | 別人變強，自己的封頂門檻就跟著變 |
| bonus 的 taper | pr = pred0 在 MIN≥500 球員中的百分位 | 別人變動，自己的 pr 就變 |

所以能力值完全沒變的球員 OVR 也會動（例：Y4 N=5 Paul George +0.604；Y3 Tony Allen 86.57→86.48）。

## 2. 改了什麼（只動預測端）

`v5/tools/pointwise_pipeline.py`：每個起點在開季用 A（先驗卡）算一次原管線，之後固定：

1. **封頂門檻 T(A)**：用 A 的 pred 排序，整季固定。
2. **pr**：每位球員固定為自己在 A 的 pr，所以 taper 與 bonus 整季不變。

結果：OVR 只看球員自己的能力值；能力值沒變，OVR 一分不變。

- **A 完全不變**：逐點版在 A 點與原管線差 <1e-8（建構時檢查，不過就中止）。
- **答案卡不變**：答案卡仍是凍結 v58 管線吃整季能力值（照 v5 §R.3），名次參考用目標季全體。
- **一體適用**：C3、C4、B 的賽中 OVR 全部用逐點版；不是只給 C4。

## 3. 試過的版本（全部記錄，含沒採用的）

詳細數字在 `backtest/c4-equiv-pointwise-trials.json`。T1 在 N≤20 的最大差：

| 版本 | 內容 | T1 最大差 | 結果 |
|---|---|---:|---|
| legacy | 原管線 | 0.604 | 3 格不過 |
| pool | T 與 pr 參考池固定在 A，pr 仍是階梯百分位 | 1.087 | 8 格不過 |
| interp | pr = A 值＋線性內插增量 | 0.543（只量 Y3 N=3） | 不過 |
| **frozen-pr（採用）** | T 固定在 A、pr 固定為 A 值 | **0.168** | 全過 |

- pool 版更差的原因：pr 是階梯函數。Middleton（Y3 N=3）能力值最大只動 0.034，pred0 跨過參考池裡一個人，pr 94.90→95.47，bonus 0.242→0.117，OVR 跳 1.09。原管線本來就有這個跳動，只是名次參考跟著動時被部分抵銷。
- interp 版仍不過：Middleton 的 pred0 和參考池另一人幾乎一樣，內插斜率很陡。
- 採用 frozen-pr 的理由：它是「能力值沒變就不變」最直接的實作，而且不用再挑任何平滑參數；OVR 只經 pred0、align、封頂變動，三者對能力值連續、斜率有界。T1 隨 N 單調變大（N=3 約 0.03、N=20 約 0.16），符合「k 固定時 n 越大更新越多」。

## 4. 分岔路揭露

- 這個改動是**看過 T1 等價檢定數字之後**做的，並且試了四版才通過；這是在調「OVR 算法」讓檢定過，必須寫明。
- 沒看過的：任何起點的 A／C3／C4 誤差、中位數、MAE、bootstrap，或 λ、c 的選擇。
- 改動對 A 沒有影響，對 C3、C4 同樣適用，所以不會只偏袒其中一個候選。
- 代價：N=82 時預測端用開季名次參考、答案卡用季末名次參考，兩者本來就不同；這部分會出現在 errata §5.2 的 N=82 拆解裡（「全部換成答案卡能力值」那一欄就是純管線／RAPM 差）。

## 5. 等價檢定最終結果

`backtest/c4-equiv.json`：pass=true。T1 N≤20 最大 0.168；T2 最大 2.8e-14；T3 0。原管線的 T1 差另存在每格的 `legacyMaxAbsOvrDiff`。
