3. errata-c4 寫「沒有 v6」。本輪是使用者決定另開，不推翻 v5 的結論：沒過就繼續用 C4。

## 2. 賽中 RAPM 窗 R_N

對起點 s：預測窗季集 P、答案窗季集 Q、目標季 t。

- **權重**：每個 stint 觀測的權重原本是回合數，改成 回合數 × m。
  - 季在 P 也在 Q：m = 1。
  - 季在 P、不在 Q（被淡出的最舊季）：m = 1 − f。
  - 目標季 t：只放該場比賽是**兩隊各自前 N 場之內**的比賽，m = 1。
  - 實作方式：points 與 possessions 同乘 m，y = 100·points/poss 不變，權重變為 m 倍。
- **f = min(N / G_t, 1)**，G_t：
  - 82；
  - 2020-21 為 72；
  - 2019-20 為各隊實際場數的中位數。
- **端點**：
  - N=0 時 R_0 ＝ 預測窗；
  - N=82 時 R_82 ＝ 答案窗。目標季全部比賽都放進來，因為 f=1，淡出季的權重為 0。
- **擬合**：
  - 直接呼叫 `reports/impact-rapm/rapm.py` 的 `observations`、`fit_rapm`；
  - λ 候選值與依比賽分組的 5 折 CV 和既有窗相同，每次擬合各自用 CV 選 λ（既有九窗都選 3000）；
  - 不加 box prior（同 Path A 窗）。
- **管線欄位**：輸出 pooledNet/O/D/Poss，與 `rapm_windows_pathA.to_pipe` 相同。poss 用加權後的回合數，所以淡出季的回合數變少，H1 的 poss≥5000 與 bonus 的回合門檻照常套用。
- 各起點的窗：

| 起點 | P | Q | 淡出季 |
|---|---|---|---|
| Y1 | 2014-15～2015-16 | 2014-15～2016-17 | 無 |
| Y2 | 2014-15～2016-17 | 2014-15～2017-18 | 無 |
| Y3 | 2014-15～2017-18 | 2015-16～2018-19 | 2014-15 |
| Y4 | 2015-16～2018-19 | 2016-17～2019-20 | 2015-16 |
| Y5 | 2016-17～2019-20 | 2017-18～2020-21 | 2016-17 |
| Y6 | 2017-18～2020-21 | 2018-19～2021-22 | 2017-18 |
| D1 | 2021-22～2022-23 | 2021-22～2023-24 | 無 |
| D2 | 2021-22～2023-24 | 2021-22～2024-25 | 無 |
| D3 | 2021-22～2024-25 | 2022-23～2025-26（`impact-rapm/rapm.csv` 四季合併欄） | 2021-22 |

若某起點的 Q 除了 t 之外還有不在 P 的季，該起點停止，不硬湊，並在報告中列出。

## 3. 賽中 OVR

- 仍用 `pointwise_pipeline`：封頂門檻 T 與 pr 固定在 A 的開季值（A 用預測窗算）。
- RAPM 相關欄位改用 R_N：r、centeredD、poss，以及 allowed（RAPM 名次加回合門檻）。
- 理由：RAPM 是新資訊，不是「別人變了自己跟著變」。allowed 雖然是 RAPM 名次，但它在原設計中就屬於 RAPM 本身的輸出，不是 OVR 名次耦合。
- 此處違反了「能力值沒變，OVR 就不變」：能力值沒變但本季 RAPM 變了，OVR 會動。這是使用者這次要的效果，報告中寫明。

## 4. 先決檢定 R1（不過就停）

每個起點：

- R_0 與既有預測窗 pipe 檔：逐球員 |net| 差 ≤ 0.01（既有檔四捨五入到 3 位）。
- R_82 與答案窗：逐球員 |net| 差 ≤ 0.01。D3 對 `impact-rapm/rapm.csv` 的四季合併欄。

任一起點不過，該起點改為只報告並寫明原因。Y5 或 Y6 不過，整輪停止。

## 5. 判定（主判定起點 Y5、Y6；門檻與種子沿用 v5）

照順序全部成立才上線 C4R，否則維持 C4。

- **G1（對 A）**：C4R 對 A 通過 v5 §2 的 V1／V2。內容與 Path A 相同：B=2000、seed 20261027、U_pool ≤ 0.50、T_s ≤ +0.25、V2 dMAE<0 且 gt10 不增加。
- **G2（對 C4 不劣）**：N=3、5、10、20，Y5、Y6 每一格都要
  - MAE(C4R) − MAE(C4) ≤ **+0.10**，且
  - 中位絕對誤差(C4R) − 中位絕對誤差(C4) ≤ **+0.10**。
- **G3（對 C4 有幫助）**：N=20 時，Y5、Y6 等權平均的 MAE(C4R) − MAE(C4) **< 0**（點估計）。

Bootstrap：

- G1 用 rng = default_rng(20261027)，起點照鏈順序、N 由小到大。
- 另報 C4R−C4 的 dMAE 95% CI，用另一個 rng，同一 seed，只報告。

## 6. 報告（不當門檻）

1. Y3、D1–D3 的 G1–G3 是否同方向。
2. N=82：C4R 與 C4 的 MAE，以及 Path A §5.2 的拆解（C4R 預期只剩能力值差，約 1.3 分，加上名次參考約 0.4 分）。
3. MAE 對 N 是否單調（errata §5.1 規則：相鄰 N 升超過 0.10 就標「非單調」）。
4. 上場時間三組（<15、15–28、≥28）的 C4 與 C4R。
5. AR 對 A：RAPM 單獨的效果。
6. 每個 R_N 選到的 λ；目標季放進來的比賽數與回合數。
