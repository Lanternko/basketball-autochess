# 以 RAPM 校準的 box score OVR（2025–26）

**結論：這是目前最接近真實影響力的 OVR。** 預測球員真實淨影響時，交叉驗證 R² 為 0.34；原本手動設定權重的期望產出 OVR 只有 0.24。全部計算約 2 秒。

box score 看不出外線防守，所以 Herbert Jones、Marcus Smart 這類防守專家仍然被低估。對實際球員，下一步是「以 box score 預測值為先驗的 RAPM」，可以補上這一塊。

`python3 reports/ovr-rapm-calibrated-2025-26/fit.py`，輸出 `ranking.csv`、`summary.json`、`priors.csv`。

## 做法

做法和 BPM 相同：每項數據值多少分，由真實影響力資料決定，不由人主觀設定。

- **目標**：四季合併的 RAPM（`reports/impact-rapm/rapm.csv`），進攻（O）與防守（D）分開擬合，淨值為兩者相加。
- **輸入**：2025-26 每 100 回合的數據率。
  - 進攻：得分、出手數、三分出手、罰球出手、助攻、被傳球創造的進球、失誤、進攻籃板。
  - 防守：防守籃板、抄截、阻攻、犯規、在場時對手每次出手少得的分數、身高。
- **擬合**：Ridge 迴歸，權重為 RAPM 回合數（上限 20,000），正則化強度由重複 5 折交叉驗證決定。訓練樣本是 345 位 RAPM 至少 5,000 回合、2025-26 至少 500 分鐘的球員。
- **小樣本收縮**：每項數據率視為 Poisson 計數，依擬合出的權重算出預測值的抽樣變異，再用經驗貝氏往同角色的平均拉回（先驗只依場均分鐘，不扣缺賽）。

## 各項數據的價值（每 100 回合多 1 次，對每 100 回合淨影響的分值）

| 進攻 | 分值 | | 防守 | 分值 |
|---|---:|---|---|---:|
| 失誤 | −0.60 | | 抄截 | +0.83 |
| 進攻籃板 | +0.37 | | 阻攻 | +0.34 |
| 得分 | +0.35 | | 在場時對手每次出手少 1 分 | +0.13 |
| 助攻 | +0.28 | | 防守籃板 | +0.06 |
| 出手數 | −0.26 | | 犯規 | −0.04 |
| 被傳球創造的進球 | −0.20 | | 身高（每吋） | +0.08 |
| 三分出手 | +0.14 | | | |
| 罰球出手 | +0.07 | | | |

這些權重都很合理：

- **得分 ＋ 出手數合起來看**，就是效率：多投但不多得分會扣分。
- **被傳球創造的進球是負值**：被餵出來的進球，功勞有一部分屬於傳球者。
- **三分出手是正值**：拉開空間的價值，和你說的牽制效果一致。
- **抄截是防守中最有價值的數據**：這正是模擬裡缺少的外線防守。
- **防守籃板幾乎不值分**：籃板大多是團隊功勞。所以之前懷疑「籃板被高估」，在模擬和手動權重裡都成立。

## 以 box score 為先驗的 RAPM：第一次結果

在本機執行 `rapm.py --prior` 後，預測沒看過的比賽時，加權誤差如下：

| | 一般 RAPM | 先驗版 | 差距 |
|---|---:|---:|---:|
| 四季合併 | 4329.26 | 4326.40 | −2.86 |
| 2025-26 單季 | 4621.92 | 4607.17 | **−14.75** |

**先驗有幫助。** 單季版改善了 14.75，比把一般 RAPM 的正則化強度從最差調到最好的差距（約 36）的三分之一還多。單季樣本少，所以 box score 先驗的幫助比較大。這個比較對先驗略有利，因為 box score 權重是用同一批比賽的 RAPM 擬合的。

**但第一版先驗有錯誤：`priors.csv` 寫入的是收縮前的預測值。** 結果只打 92～123 回合的球員，被未收縮的極端預測推上榜首：Tristen Newton +9.4、Alex Antetokounmpo +8.2、Norchad Omier +6.0。

**已修正：** 進攻和防守分別依各自的抽樣變異收縮，`priors.csv` 改寫入收縮後的值（例如 Newton 從 +9.5 變成 −0.3）。這個錯誤只影響回合數極少的球員；回合數多的球員，結果由比賽資料主導。

**先驗版的排名相關不能拿來比。** `rapm-prior-summary.json` 裡期望產出 OVR 的相關升到 0.61～0.72，但先驗本身就來自 box score，這是循環論證，不代表變準。

**防守專家的評價會下降。** 先驗版的正則化強度從 3000 變成 10000，比較依賴 box score：Herbert Jones 從 +5.30 降到 +2.85、Marcus Smart 從 +4.20 降到 +2.60。這是用「預測沒看過的比賽更準」換來的取捨。

## 最終 OVR（實際球員）

修正後的先驗需要在本機重跑一次：

```
python3 reports/impact-rapm/rapm.py --prior reports/ovr-rapm-calibrated-2025-26/priors.csv
python3 reports/ovr-final-2025-26/build.py
```

`build.py` 讀取 `rapm-prior.csv` 的 2025-26 單季先驗版，依 PR1=40、PR50=70、PR99=99 換算成 OVR，輸出 `reports/ovr-final-2025-26/ranking.csv`。也可以加 `--source pooled` 改用四季合併版。

## 限制

- RAPM 本身有正則化，也混有教練安排、陣容搭配、垃圾時間等因素，不是純因果真值。
- 四季合併的 RAPM 混入能力隨年份的變化，而輸入只用 2025-26 的數據。
- 這個公式的輸入是 box score 數據，**不是卡片能力值**。虛構卡片仍需要能力值版的公式（`reports/ovr-calibrated-2025-26`）。下一步可以把能力值版的目標，從模擬改成 RAPM。
