# v39 球隊誤差來源診斷

核對四季全部 4,920 場 box score、賽程比分與封存勝負來源後，將120個球隊賽季的淨得分誤差精確拆成己方／對手、兩分／三分／罰球、出手量／命中率。這是計算診斷，沒有改模型或調整係數。

v39 勝場 MAE 為6.2222，正式封存模型為5.3278。合併120個球隊賽季的淨得分 RMSE 為2.8903分，正式模型為2.8160分。這裡的合併 RMSE 與先算各季 RMSE 再平均不同。

v39 的誤差分量與總淨得分誤差內積投影中，對手端占0.8884，己方端0.1116；命中率端占0.8135，出手量端0.1865。最大一項是對手兩分命中率0.3993。投影可因抵消而為負或大於1，不能解讀成因果比例或獨立變異解釋率；此結果只用於決定下一個應檢查的機制。

以預期命中數替換條件式投籃命中亂數後，淨得分 RMSE 仍為2.7336分；罰球、出手選擇、回合等上游隨機性仍在，不能視為已去除全部模擬雜訊。

2025–26部分賽季彙總與逐場來源有出手／失誤等差異，完整紀錄在 `audit.json` 的 `sourceAudit`，未隱藏或回填；本診斷對球隊比分／勝負採比對賽程後的逐場來源，按 teamId 對應，保留原始檔案。部分來源主客順序與賽程不同，因此不以陣列位置推定球隊。

`verification.json` 已獨立核對240筆版本／球隊賽季分解、比分及雜湊；完整計算與每隊各項誤差在 `audit.json`。後續 v40／v41 研究控制投籃者後的五人防守陣容關聯，尚不能因此宣稱個人防守能力已被純粹量測。
