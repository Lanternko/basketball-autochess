- 實驗 ID：E-148。
- 來源：M4（E-146、R-099）上線後，lead 指出「球隊大勝時投不好的人也被正負值加分」（例：Mitchell 18 投 5 中，M2 5.5 → M4 7.3）。lead 列了四個方案，使用者選 3：「相對正負值，再扣掉垃圾時間」。
- 動到的裁決：R-099。驗收通過、使用者核准後才改；只顯示用，不進 OVR。

  - β_q＝0 版：T1 0.277、T2 0.702。
  - Mitchell 例子。
  - 沒看過任何相對正負值或扣垃圾時間的數字。

## 1. 和 M4 的差別

只換正負值 q，其他照 M4 不變：v、整場總量、K／R／a／c 的規則都一樣。

| | M4 | M5 |
|---|---|---|
| q | box 的 PLUS_MINUS × 36/MIN | **非垃圾時間**裡，他在場每 36 分鐘的淨分，**減掉全隊同期每 36 分鐘的淨分** |
| 選 β_q 的 J | 含「單場 vs 球隊淨勝分」 | **拿掉淨勝分**（避免循環），改用 EPM＋DARKO |

## 2. 定義

### 資料
- 2025-26 回合段（stints）：`reports/defense-b1/stints.jsonl`。
- 2026-27 回合段（stints）：`reports/defense-seventh/2026-27/stints/stints.jsonl`（每日流程會重產）。
- 每段的欄位：period、startClock／endClock、seconds、兩隊 lineups，以及每隊 `opponent.points`（對手在這段的得分）。
- 這兩份 stints 只含正規時間，且有些場次被排除。

### 垃圾時間
- 從各段的得分累加，重建每段開始時的比分差。
- **某段若 period ≥ 4，且開始時比分差的絕對值 ≥ 20，這段就是垃圾時間。**
- 規則固定，不准調。

### 相對正負值
針對某球員、某場：
- PM_ng、S_ng：他在非垃圾時間在場時，球隊的淨分與秒數。
- M_ng、T_ng：全隊在非垃圾時間的淨分與總秒數。
- `q = 36·60·(PM_ng/S_ng − M_ng/T_ng)`，也就是他在場時每 36 分鐘的淨分，減掉全隊平均。
- S_ng < 60 秒時，q＝0。

### 資料檢查 V0（先做，不看任何評分）
- 對 2025-26 與 2026-27 中 ≥10 分鐘的球員單場，用 stints 加總（含垃圾時間）出 PM，和 box 的 PLUS_MINUS 比對。
- 下列兩種情況該場改用退回值：
  - 這場不在 stints 裡。
  - 該場有任何球員差距 > 2 分。
  - 有 OT 的場次照上面兩條判斷，OT 段不在 stints 裡也不額外處理。
- 退回值：`q = 36·(PLUS_MINUS/MIN − 球隊淨勝分/48)`，即不扣垃圾時間的相對值。
- 報告要寫比對一致的比例與退回的場次數。
- 2025-26 一致比例 < 85% → 停，回報，不往下做。

## 3. 參數規則
- 只用 2025-26 A 半，即 `int(GAME_ID)%2==0`。
- 寫進 `reports/rating-m5/params.json`，單獨 commit 後才准算 B 半與 2026-27。

規則：
- **β_q 格點**：{0, 0.1, 0.2, 0.3, 0.5, 0.75, 1.0}。
  - 限制：q 項在 ≥10 分鐘單場 G 的變異佔比 ≤ 30%，算法同 E-146。
  - 每個候選都照 M4 規則重定 μ、K、R、a、c。
- **J**：`ρ(球員 A 半平均評分, 自製 EPM net) + ρ(球員 A 半平均評分, DARKO dpm)`，只算 A 半 ≥250 分鐘的球員。
  - 取最大；同分取較小的 β_q。
- **五色切點、上線版**：同 M4。上線版的 β_q 用 A 半選定值，其他參數用整季重算。
- 選完不准改格點、J、垃圾時間門檻（L-026）。
